## 0. 기본 위젯과 커스텀 위젯

고객 사이트에 뜨는 채팅 위젯의 모양은 **두 층**으로 정해집니다.

```
위젯 테마 카드 (기본 위젯)            ── 항상 적용
  브랜드 색 · 헤더 스타일 · 로고 · 런처 위치/크기/아이콘
        │
        ▼  [사용함]인 커스텀 위젯이 있으면 그 위에 덧씌움
커스텀 위젯 (디자인 라이브러리)        ── 사용함일 때만 적용
  폰트 · 글자 크기 · 모서리 · 패널 크기 · 아이콘 파일 · (애드온) 정제 CSS
```

| 용어 | 뜻 |
|---|---|
| 기본 위젯 | 위젯 테마 카드의 설정만으로 그려지는 위젯. 커스텀 위젯을 하나도 사용하지 않으면 고객은 이것을 봅니다 |
| 커스텀 위젯 | 이름을 붙여 저장한 **디자인 한 벌**(폰트·크기·모서리·패널·아이콘·CSS). 여러 개를 만들어 두고 그중 하나만 [사용함]으로 켭니다 |
| 라이브러리 | 커스텀 위젯 카드의 목록. 사용 중·보관됨 상태와 액션 버튼(미리보기·편집·복제·내보내기·이력·보관·삭제)이 있습니다 |
| 디자인 파일 | 커스텀 위젯이 참조하는 폰트·아이콘·이미지·시안 파일. 테넌트 전용 폴더에 보관되며 배포와 무관하게 유지됩니다 |
| 사용함 | 라이브러리의 디자인 하나를 고객 위젯에 적용하는 버튼. **배포 없이 즉시** 반영됩니다 |

**언제 커스텀 위젯이 필요한가**
- 브랜드 폰트를 위젯에도 쓰고 싶을 때 (테마 카드는 색만 바꿉니다)
- 시즌·캠페인마다 다른 모양을 미리 만들어 두고 날짜에 맞춰 바꿔 끼우고 싶을 때
- 데스크톱 패널을 더 크게/작게, 모서리를 더 둥글게 하고 싶을 때
- 런처 버튼에 직접 만든 아이콘을 쓰고 싶을 때

색·로고·런처 위치만 바꾸면 된다면 커스텀 위젯 없이 **위젯 테마 카드**만으로 충분합니다.

💡 **팁**: 커스텀 위젯은 테마 카드를 **대체하지 않고 덧씌웁니다**. 브랜드 색을 바꾸고 싶으면 커스텀 위젯을 편집하지 말고 테마 카드를 바꾸세요 — 사용 중인 디자인이 무엇이든 즉시 함께 적용됩니다.

## 1. 준비 — 디자인 파일

커스텀 위젯에서 **업로드한 폰트**나 **아이콘 파일**을 쓰려면 먼저 디자인 파일 카드에 올려 두어야 합니다. 프리셋 폰트와 테마 카드의 런처 아이콘만 쓸 거라면 이 장을 건너뛰어도 됩니다.

![디자인 파일 카드 — 종류 탭·용량 바·파일 추가](img/cw-design-files.ko.jpg)

### 1.1 종류별 규격

| 종류 | 형식 | 상한 | 공개 여부 | 쓰임 |
|---|---|---|---|---|
| 폰트 | woff2 · ttf · otf | 2MB | 공개 (위젯이 직접 내려받음) | 편집기의 「업로드한 폰트」 |
| 아이콘 | png · webp | 256KB · 512×512px | 공개 | 편집기의 「아이콘 파일」(런처 버튼) |
| 이미지 | png · jpg · webp | 2MB · 2000px | 공개 | 시안 공유·URL 복사용 (위젯이 자동으로 쓰지는 않음) |
| 시안·가이드 | pdf · png · jpg | 10MB | 비공개 (서명 URL) | 디자인 시안·브랜드 가이드 보관 |

- 디자인 영역 전체 상한은 **50MB**입니다(카드 오른쪽 위 용량 바). 가득 차면 파일 추가가 거부됩니다(E5084).
- **svg · css · js는 받지 않습니다.** 파일 내용을 검사하므로 확장자만 바꿔도 통과하지 않습니다(E5081).
- 아이콘·이미지는 서버에서 다시 인코딩됩니다. 픽셀 상한을 넘으면 거부됩니다(E5083).

### 1.2 업로드 절차

1. 설정 > 위젯 설정 > **디자인 파일** 카드에서 종류 탭(폰트/아이콘/이미지/시안·가이드)을 고릅니다.
2. **[파일 추가]** → 파일 선택. 목록에는 파일명이 이름으로 표시됩니다.
3. 목록에 행이 생기면 완료입니다. 파일을 바꾸려면 새 파일을 올리고 편집기에서 새 파일을 고른 뒤 이전 파일을 삭제하세요(같은 이름을 올려도 덮어쓰지 않고 새 행이 생깁니다).
4. 공개 파일은 **[URL 복사]**로 주소를 얻을 수 있습니다(사이트 다른 곳에서 같은 폰트를 쓸 때). 시안·가이드는 [다운로드]만 됩니다.

⚠️ **폰트 라이선스**: 업로드한 폰트를 고객 브라우저에 배포하는 것은 테넌트의 책임입니다. 웹 임베딩이 허용된 폰트만 올리세요.

💡 **팁**: 폰트는 **woff2**가 가장 작고 빠릅니다. ttf/otf도 되지만 2MB 상한에 걸리기 쉽고 고객 첫 로드가 느려집니다. 한글 폰트는 서브셋(subset) woff2를 권장합니다.

## 2. 만들기 — 커스텀 위젯 편집기

![커스텀 위젯 만들기 — 필드와 간이 미리보기](img/cw-editor.ko.jpg)

설정 > 위젯 설정 > **커스텀 위젯** 카드 → **[커스텀 위젯 만들기]**.

### 2.1 필드

| 필드 | 값 | 설명 |
|---|---|---|
| 이름 | 64자 이내, 테넌트 안에서 유일 | 라이브러리에 표시되는 이름. 같은 이름이 있으면 저장이 거부됩니다(E5087) |
| 폰트 | Pretendard(기본) · Noto Sans KR · Inter · 시스템 폰트 · 업로드한 폰트 | Noto Sans KR·Inter는 Google Fonts에서 불러옵니다. 「업로드한 폰트」를 고르면 **폰트 파일** 선택란이 나타납니다(1장) |
| 기본 크기 | 13 ~ 16px (기본 14) | 글자와 **간격을 함께** 키우거나 줄입니다. 위젯 전체가 확대/축소되는 것과 같습니다 |
| 모서리 | 작게 8px · 보통 12px · 크게 16px | 패널 모서리. 말풍선·버튼은 비율에 맞춰 따라갑니다 |
| 패널 크기 | 폭 360~480 · 높이 480~720 (기본 404×600) | **데스크톱만** 적용. 모바일·앱 모드는 화면을 채웁니다 |
| 아이콘 파일 | 위젯 테마 카드의 런처 아이콘(기본) · 업로드한 아이콘 | 런처(둥근 버튼)의 그림. 업로드 아이콘을 고르면 테마 카드의 아이콘 선택은 무시됩니다 |
| 빠른 답장 스타일 | 채움 칩(기본) · 아이콘 카드 | 채팅 첫 화면의 시나리오 버튼 모양입니다. 카드는 흰 배경에 외곽선과 아이콘이 붙습니다 |
| 커스텀 CSS (애드온) | 정제 CSS | 플랫폼 관리자가 애드온을 켠 테넌트에만 보입니다(5장) |
| 메모 | 자유 텍스트 | "2026 봄 시즌, 담당 ○○" 같은 운영 메모. 고객에게 보이지 않습니다 |

오른쪽 **간이 미리보기**는 폰트·크기·모서리를 대략 보여 주는 것입니다. 실제 위젯의 모양은 저장 뒤 **[미리보기]**(3장)로 확인하세요.

### 2.2 저장 두 가지

| 버튼 | 결과 |
|---|---|
| **[보관함에 저장]** | 라이브러리에만 넣습니다. 고객 위젯은 그대로입니다. 먼저 미리보기로 확인할 때 씁니다 |
| **[저장 후 사용함]** | 저장하고 곧바로 고객 위젯에 적용합니다. 이미 사용 중이던 디자인은 자동으로 해제됩니다 |

💡 **팁**: 처음 만들 때는 **[보관함에 저장] → [미리보기] → [사용함]** 순서를 권장합니다. 편집기의 간이 미리보기는 브랜드 색·로고·탭 구성을 반영하지 않으므로, 실제 위젯을 열어 봐야 전체 인상을 알 수 있습니다.

💡 **팁**: 글자 크기를 16px로 올리면 패널이 좁게 느껴집니다. 기본 크기를 키울 때는 패널 폭도 함께 늘리세요(예: 15px + 440×640).

## 3. 확인·적용 — 미리보기 → 사용함

![커스텀 위젯 라이브러리 — 현재 상태·행 액션](img/cw-library.ko.jpg)

### 3.1 실제 위젯 미리보기

행의 **[미리보기]**를 누르면 데모 스토어 페이지 위에 **실제 위젯**이 그 디자인으로 열립니다.

- **10분짜리 미리보기 토큰**으로 로드됩니다. 고객에게는 아무 영향이 없고, 10분이 지나면 다시 [미리보기]를 누르면 됩니다.
- 미리보기를 열려면 **스토어 도메인**이 설정되어 있어야 합니다(설정 > 기본 설정 > 스토어프런트). 없으면 안내 문구가 대신 나옵니다.
- 미리보기 안에서 채팅을 보내면 실제 데모 세션이 생깁니다 — 문구 확인 정도로만 쓰세요.

![실제 위젯 미리보기 모달](img/cw-preview.ko.jpg)

### 3.2 사용함 · 기본 위젯으로 복귀

| 동작 | 결과 |
|---|---|
| 행의 **[사용함]** | 그 디자인이 고객 위젯에 적용됩니다. 카드 상단 「현재:」가 **커스텀 "이름" 사용 중**으로 바뀌고 행에 **사용 중** 배지가 붙습니다 |
| **[기본 위젯으로 복귀]** | 커스텀 적용을 해제합니다. 위젯 테마 카드만으로 그려지는 기본 위젯으로 돌아갑니다. 디자인은 라이브러리에 그대로 남습니다 |

적용은 **배포 없이 즉시** 이루어집니다. 서버가 테넌트 전용 "라이브 파일"을 다시 쓰고, 고객 위젯은 다음 로드 때 그 파일을 읽습니다.

- 새로 페이지를 여는 고객: 바로 새 디자인
- 이미 위젯을 열어 둔 고객: 페이지를 새로고침하면 새 디자인
- 위젯이 캐시해 둔 이전 테마를 먼저 그린 뒤 라이브 파일로 갱신하므로, 아주 짧게 이전 모양이 보일 수 있습니다

### 3.2-1 진입 방식 — 플로팅 버튼 vs 스토어 헤더 트리거

위젯을 여는 방법은 두 가지이고, **설정 > 위젯 설정 > 위젯 테마 > 런처 모드**에서 고릅니다.

| 모드 | 동작 |
|---|---|
| **플로팅 버튼**(기본) | 화면 우하단(또는 좌하단)에 둥근 버튼이 떠 있고, 누르면 그 위로 패널이 열립니다 |
| **스토어 헤더 트리거** | 떠 있는 버튼이 없습니다. **스토어가 가진 요소**(예: 헤더의 종 아이콘)를 누르면 패널이 **헤더 바로 아래 우측에 도킹**되어 열리고, 패널 바깥을 클릭하면 닫힙니다 |

트리거 모드를 고르면 두 값을 더 채웁니다.

- **트리거 선택자**: 위젯을 여는 요소의 CSS 선택자(예 `#st-bell`).
- **상단 오프셋**: 패널이 시작할 화면 상단으로부터의 거리(px). 헤더 높이와 같게 맞추면 헤더에 붙습니다.

스토어 테마(머리말)에 여는 요소를 넣고, 설치 스니펫의 `trigger`에 같은 선택자를 적습니다. 콘솔이 복사용 예시를 함께 보여 줍니다.

```html
<button id="st-bell" type="button" aria-label="Notifications">🔔
  <span data-sharptalk-badge style="display:none"></span>
</button>
```

- `data-sharptalk-badge` 요소에는 **읽지 않은 알림 수**가 자동으로 들어가고, 0이면 숨겨집니다.
- 좁은 화면(휴대폰)에서는 패널이 화면을 채우고 **닫기(X)가 그대로 남습니다** — 전체 화면에는 "바깥"이 없기 때문입니다.
- 트리거 모드에서는 헤더의 언어 선택과 X가 보이지 않습니다. 언어는 톱니(설정) 안에서 바꿉니다.

### 3.3 사용 중인 디자인 편집

**사용 중** 배지가 붙은 디자인을 [편집]하면 저장 시 경고가 나옵니다: *"사용 중인 디자인입니다 — 저장하면 고객 위젯에 즉시 반영됩니다."*

⚠️ **권장 절차**: 사용 중인 디자인은 직접 고치지 말고 **[복제] → 복제본 편집 → [미리보기] → [사용함]** 으로 바꾸세요. 실수해도 이전 디자인이 라이브러리에 그대로 있어 한 번에 되돌릴 수 있습니다. 급히 고쳐야 한다면 직접 편집해도 되며, 잘못됐을 때는 **[이력]**에서 이전 버전으로 복원합니다(4.1절).

## 4. 운영 — 되돌리기·이관

디자인을 "되돌리는" 수단은 세 가지이고 범위가 다릅니다.

| 수단 | 범위 | 되돌리는 단위 | 다른 테넌트·환경으로 옮기기 |
|---|---|---|---|
| **이력** (4.1) | 디자인 1개 | 저장 시점 단위(리비전) | 불가 |
| **패키지** (4.3) | 디자인 1개 + 동봉 폰트·아이콘 | 파일 단위 | **가능** (JSON 내보내기 → 가져오기) |
| **설정 스냅샷** (4.4) | 위젯 테마·문구·탭 등 설정 12항목 + 커스텀 위젯 라이브러리 전체 | 스냅샷 시점 | 다운로드는 가능, 반입은 같은 테넌트의 복원만 |

### 4.1 변경 이력

![변경 이력 모달 — 리비전 목록과 복원](img/cw-history.ko.jpg)

- 디자인을 **저장할 때마다 저장 직전 상태**가 리비전(#1, #2 …)으로 남습니다. 이름이나 메모만 바꾼 저장은 리비전을 만들지 않습니다.
- 행의 **[이력]** → 목록에서 **[이 버전으로 복원]**. 복원하면 지금 상태도 리비전으로 남으므로 복원을 다시 되돌릴 수 있습니다.
- 사용 중인 디자인을 복원하면 고객 위젯에 즉시 반영됩니다(3.3절 경고와 동일).
- 목록은 최신 50건까지 보여 줍니다. 디자인을 삭제하면 이력도 함께 삭제됩니다.

### 4.2 복제 · 보관 · 삭제

| 동작 | 규칙 |
|---|---|
| 복제 | 같은 디자인을 "(copy)", "(copy 2)" 이름으로 만듭니다. 시즌 변형을 만들 때의 출발점입니다 |
| 보관 | 목록에서 숨깁니다. **사용 중인 디자인은 보관할 수 없습니다**(E5086) — 먼저 다른 디자인을 [사용함]하거나 [기본 위젯으로 복귀]하세요. 카드 오른쪽 위 **보관함 표시**를 켜면 보관된 행이 보이고 [복원]할 수 있습니다 |
| 삭제 | 되돌릴 수 없습니다. 사용 중이면 거부됩니다(E5086). 이력도 같이 지워집니다 |

### 4.3 패키지 내보내기 · 가져오기

- 행의 **[내보내기]** → `sharptalk-widget-design` JSON 파일이 내려받아집니다. 디자인이 참조하는 **업로드 폰트·아이콘 파일이 함께 동봉**되므로 파일 하나로 완결됩니다.
- 카드 오른쪽 위 **[패키지 가져오기]** → JSON 선택(12MB 이하). 동봉된 폰트·아이콘은 업로드와 같은 내용 검사를 거쳐 디자인 파일에 다시 등록되고, 이름이 겹치면 "(2)"가 붙습니다. 가져온 디자인은 **보관함에만** 들어가며 사용함은 직접 눌러야 합니다.
- 쓰임: 다른 테넌트(브랜드가 여러 개인 운영자)나 다른 환경으로 디자인 옮기기, 외부 디자이너와 파일로 주고받기.

### 4.4 설정 스냅샷 (설정 > 기타 설정)

![설정 스냅샷 복원 — 현재와 스냅샷 비교](img/cw-snapshot-diff.ko.jpg)

- 설정 > **기타 설정** > **설정 스냅샷** 카드 → 라벨(예: "배포 전") 입력 → **[스냅샷 저장]**.
- 저장되는 것: 위젯 테마·문구·탭·탭 위치·로그인 방식·알림 채널·임베드 오리진·지식 옵션·타임존·스토어프런트·개인정보 안내 + **커스텀 위젯 라이브러리 전체**(이름·상태·디자인·사용 중 여부). 연동 자격증명과 임베드 시크릿은 **포함되지 않습니다**.
- **[복원…]** → 현재 값과 스냅샷 값이 항목별로 나란히 나오고 바뀌는 행이 강조됩니다. 맨 아래 "커스텀 위젯: 생성 n · 갱신 n · 복원 후 사용함: 이름"으로 라이브러리에 일어날 일을 미리 보여 줍니다. [복원]은 감사 기록에 남습니다.
- 큰 변경(시즌 전환, 문구 일괄 수정) 전에 스냅샷을 하나 찍어 두는 것이 가장 싼 보험입니다.

💡 **팁**: 이력은 "이 디자인만 조금 전으로", 패키지는 "이 디자인을 다른 곳으로", 스냅샷은 "위젯 관련 설정 전부를 그때로". 셋 중 무엇이 필요한지 먼저 정하면 헤매지 않습니다.

## 5. 확장 — 정제 CSS (애드온)

편집기 아래쪽 **커스텀 CSS (애드온)** 입력란은 **플랫폼 관리자가 이 테넌트의 "커스텀 위젯 CSS 허용"을 켠 경우에만** 보입니다(6장). 보이지 않으면 관리자에게 애드온을 요청하세요.

![CSS 입력란과 검사 결과](img/cw-css.ko.jpg)

### 5.1 무엇을 바꿀 수 있나

위젯은 **안정 클래스**라는 이름이 고정된 13개 지점을 제공합니다. 이 클래스에 **색·폰트·간격·테두리·그림자**만 입힐 수 있습니다.

| 클래스 | 지점 |
|---|---|
| `.st-panel` | 패널 전체 |
| `.st-header` / `.st-header-title` | 헤더 / 헤더 제목 글자 |
| `.st-tabs` / `.st-tab` | 탭 바 / 탭 하나 |
| `.st-message` / `.st-message-user` / `.st-message-bot` | 말풍선 공통 / 고객 / AI·상담원 |
| `.st-composer` / `.st-input` / `.st-send` | 입력 영역 / 입력창 / 보내기 버튼 |
| `.st-launcher` | 런처 버튼 |
| `.st-quick-reply` | 빠른 답장(시나리오) 버튼 |

**허용 규칙**
- 선택자: `.st-*` 클래스, 그 조합(`.st-panel .st-tab`, `.st-a > .st-b`), 끝에 `:hover` `:focus` `:active` `:first-child` `:last-child` `:disabled`만
- 속성: `color` `background(-color)` `border*` `border-radius*` `font-family/size/weight/style` `line-height` `letter-spacing` `text-*` `padding*` `margin*` `gap` `box-shadow` `outline*` `width/height`(min/max 포함)
- 값: 색상값, `rgb()/rgba()/hsl()/hsla()`, 위젯 변수 `var(--ivy-…)`, 숫자·단위·키워드
- 상한 32KB

**제거되는 것(저장 시 자동으로 걸러지고 사유가 표시됩니다)**
- 위치·숨김·겹침: `display` `visibility` `opacity` `position` `transform` `z-index` `content`
- 외부 자원: `url()` `@import` `@font-face` `@media` 등 모든 `@` 규칙
- `.st-` 이외의 선택자(`body`, `#id`, 속성 선택자), 중첩 블록, 주석 안 규칙

### 5.2 절차와 [검사]

1. 편집기 **커스텀 CSS (애드온)** 란에 규칙을 입력합니다.
2. **[검사]** → "n개 규칙이 유지됩니다"와 함께 **제거될 항목의 사유**가 나옵니다. 사유가 없을 때까지 다듬습니다.
3. 저장하면 **검사에서 통과한 규칙만** 저장됩니다(원문이 아니라 정제본이 남습니다).
4. [미리보기]로 실제 위젯에서 확인 → [사용함].

예시
```
.st-header { background-color: #111; color: #fff; }
.st-header-title { letter-spacing: 0.02em; }
.st-send { background-color: var(--ivy-primary-700); border-radius: 999px; }
.st-message-bot { border: 1px solid #e5e7eb; box-shadow: 0 1px 2px rgba(0,0,0,.06); }
```

⚠️ 헤더 제목 글자색은 `.st-header { color }`로는 바뀌지 않습니다(제목이 자기 색을 가짐). **`.st-header-title`**에 지정하세요.

💡 **팁**: 대비가 낮은 색 조합(흐린 배경에 흐린 글자)은 검사에 걸리지 않습니다. 접근성 대비(4.5:1)는 테마 카드의 브랜드 색처럼 자동 보정되지 않으므로 직접 확인하세요.

## 8. FAQ / 문제 해결

**Q. [사용함]을 눌렀는데 사이트 위젯이 그대로입니다.**
페이지를 새로고침하세요. 위젯은 캐시된 테마를 먼저 그린 뒤 라이브 파일로 갱신합니다. 그래도 그대로면 라이브러리 상단 「현재:」가 그 디자인인지, 위젯이 설치된 도메인이 설정 > 기본 설정의 스토어 도메인과 같은지 확인하세요.

**Q. 업로드한 폰트가 위젯에 안 보입니다.**
편집기의 폰트가 「업로드한 폰트」이고 **폰트 파일**에서 그 파일을 골랐는지 확인하세요. 파일이 "비공개"(시안·가이드 종류)로 올라갔다면 위젯이 받을 수 없으니 **폰트** 종류로 다시 올리세요.

**Q. [미리보기]를 누르면 "먼저 스토어 도메인을 설정하세요"라고 나옵니다.**
설정 > 기본 설정 > 스토어프런트에서 스토어 도메인을 저장한 뒤 다시 시도하세요. 미리보기는 그 도메인의 위젯 세션을 흉내 내어 엽니다.

**Q. 편집기에 커스텀 CSS 칸이 없습니다.**
플랫폼 관리자가 이 테넌트의 "커스텀 위젯 CSS 허용"을 켜야 나타납니다(6장). 켜기 전에 저장했던 디자인에는 CSS가 없으니 켠 뒤 편집하세요.

**Q. 파일 추가가 "이 종류에 맞지 않는 파일입니다"로 거부됩니다.**
확장자가 아니라 **내용**을 검사합니다. svg를 png로 이름만 바꾼 파일, 실제로는 ttf인 woff2 등이 걸립니다. 원본 형식으로 변환해 올리세요.

**Q. 모바일에서 패널 크기가 바뀌지 않습니다.**
정상입니다. 패널 폭·높이는 **데스크톱에서만** 적용되고 모바일·앱 모드는 화면을 채웁니다. 폰트·모서리·아이콘은 모바일에도 적용됩니다.

**Q. 보관하려는데 "사용 중인 디자인입니다"라고 거부됩니다.**
먼저 다른 디자인을 [사용함]하거나 [기본 위젯으로 복귀]한 뒤 보관하세요. 사용 중인 디자인은 보관·삭제 모두 막혀 있습니다.

**Q. 고객이 알림을 지울 수 있나요?**
네. 알림 탭의 **[선택]**을 누르면 행마다 체크가 생기고, **[선택 알림 삭제]**·**[전체 알림 삭제]**로 지웁니다. 고객 화면에서만 사라지며(서버에는 기록이 남습니다) 읽지 않은 수에서도 빠집니다.

**Q. 이력에 방금 한 이름 변경이 없습니다.**
이력은 **디자인(폰트·크기·모서리·패널·아이콘·CSS)이 바뀐 저장**만 남깁니다. 이름·메모 변경은 이력을 만들지 않으며 복원 대상도 아닙니다.
