SharpTalk · 설정 → 플랫폼

커머스 플랫폼 연동, 어떤 값을 어디서 찾나

/settings/platforms 에서 각 쇼핑몰을 연결할 때 넣는 사용자명·데이터베이스명· API 키 같은 값을, 플랫폼 관리자 화면 어디에서 발급·확인하는지 정리한 실무 가이드입니다. 값을 준비해 플랫폼 추가에서 플랫폼을 고른 뒤 설정 창에 입력 → 저장 → 연결 테스트로 검증하세요.

화면 구성(2026-10-19 개편) — /settings/platforms는 두 영역입니다. 연결된 플랫폼에는 자격증명을 저장한 플랫폼만 카드로 나타나며 배지는 연결됨(테스트·동기화 성공) / 오류 / 미테스트(저장만 함) 세 가지입니다. 플랫폼 추가에는 지원 플랫폼이 버튼으로 나열되고, 이미 연결된 것은 ✓로 표시됩니다. Shopify·Cafe24·WooCommerce·Odoo·Haravan 어디에도 속하지 않는 자체 개발 플랫폼이면 자체 플랫폼 버튼으로 이름·설명만 등록하면 됩니다(발급할 값 없음, 등록 즉시 "등록됨").
5개 플랫폼 · Shopify / Cafe24 / WooCommerce / Odoo / Haravan 필드는 콘솔 라벨과 1:1 대응
플랫폼 Shopify01 Cafe2402 WooCommerce03 Odoo04 Haravan05 문제 해결

모든 플랫폼 공통

  • 시크릿 값(토큰·시크릿·API 키)은 저장 후 다시 표시되지 않습니다 — 교체할 때만 새 값을 입력하세요.
  • URL은 반드시 https:// 공개 도메인이어야 합니다. 내부·사설 주소(로컬호스트·사내 IP)는 보안상 차단됩니다.
  • 필요한 최소 권한은 주문·고객·상품 읽기입니다. 쓰기 권한은 필요 없습니다.
  • 연결 테스트가 실패하면 카드에 사유가 표시됩니다 — 401=토큰 무효·만료, 404=주소 오류.
  • 각 단계의 화면 도식은 발급 위치를 나타낸 일러스트이며 실제 벤더 화면과 세부 명칭·배치가 다를 수 있습니다.

01Shopify

플랫폼 추가 → Shopify(또는 연결된 카드의 설정)에서 쇼핑몰 주소와 Admin API 토큰을 입력합니다.

Admin API · 커스텀 앱 토큰

SharpTalk가 요구하는 값

쇼핑몰 주소shop_domainyour-store.myshopify.com필수
Admin API 액세스 토큰access_tokenshpat_…필수시크릿
API 키 / 시크릿api_key · api_secret공개 앱(OAuth)용 — 커스텀 앱은 비워둠선택

Shopify 관리자에서 발급

  1. Settings(설정) → Apps and sales channels(앱 및 판매 채널) 로 이동합니다.
  2. Develop apps(앱 개발) → Create an app(앱 만들기) 으로 앱을 만들고 이름을 입력합니다.
  3. Configuration → Admin API integration 에서 읽기 스코프를 허용합니다.read_orders · read_customers · read_fulfillments · read_products
  4. API credentials(자격 증명) → Install app(앱 설치) 를 클릭합니다.
  5. 설치 직후 표시되는 Admin API access token(shpat_…)을 복사합니다.이 토큰은 한 번만 표시됩니다 — 즉시 SharpTalk에 저장하세요.
  6. 쇼핑몰 주소는 관리자 URL의 xxxx.myshopify.com 부분입니다(브랜드 도메인이 아님).
↔이미 SharpTalk 공개 앱의 "연결" 버튼으로 설치했다면 토큰은 자동 저장됩니다. 위 수동 입력은 커스텀 앱을 직접 쓰는 경우입니다.

02Cafe24

Admin API v2 OAuth 액세스 토큰으로 카페24 상점을 연결합니다.

Admin API v2 · Bearer(OAuth)

SharpTalk가 요구하는 값

몰 IDmall_id상점 아이디 (예: yourmall)필수
액세스 토큰access_tokenAdmin API OAuth 토큰필수시크릿
클라이언트 ID / 시크릿client_id · client_secret개발자센터 앱 값 (토큰 자동갱신 시)선택

Cafe24 개발자센터에서 확인

  1. 몰 ID — 관리자 접속 주소 yourmall.cafe24.com 의 yourmall 부분, 또는 관리자 상단의 상점 아이디입니다.
  2. 클라이언트 ID / 시크릿 — developers.cafe24.com 로그인 → 앱 만들기 → 앱의 App 정보에서 확인합니다.앱 권한(Scope)에 mall.read_order · mall.read_customer · mall.read_product 등 읽기 권한을 추가하세요.
  3. 액세스 토큰 — OAuth 절차(Authorization Code → Access Token)로 발급되는 Admin API 토큰을 붙여넣습니다.유효기간 2시간, 리프레시 토큰 14일 — 만료 시 재발급이 필요합니다.
↔설정 상단의 Cafe24 OAuth "연결" 버튼을 쓰면 몰 대표 운영자 계정으로 클릭 한 번에 연결·토큰 자동관리가 됩니다. 수동 토큰 입력이 번거로우면 권장합니다.

03WooCommerce

REST API v3 consumer key/secret(Basic 인증)으로 연결합니다.

REST v3 · Basic auth

SharpTalk가 요구하는 값

스토어 URLstore_urlhttps://store.example.com필수
Consumer keyconsumer_keyck_…필수시크릿
Consumer secretconsumer_secretcs_…필수시크릿

WordPress · WooCommerce 관리자에서 발급

  1. WooCommerce → 설정(Settings) → 고급(Advanced) → REST API 로 이동합니다.
  2. 키 추가(Add key) 를 클릭합니다.
  3. 설명 입력, 사용자(User) 선택, 권한(Permissions) 은 읽기(Read) 로 지정합니다.
  4. API 키 생성(Generate API key) → Consumer key(ck_…)와 Consumer secret(cs_…)이 표시됩니다.이 화면을 벗어나면 다시 볼 수 없습니다 — 즉시 복사하세요.
  5. 스토어 URL 은 쇼핑몰 최상위 주소입니다. /wp-admin · /wp-json 을 붙이지 마세요.
!연결 테스트는 …/wp-json/wc/v3/system_status 를 호출합니다. 404=REST API 비활성·URL 오류(퍼머링크 확인), 401=키·시크릿 불일치.

04Odoo

URL · DB · 사용자 · API 키로 외부 API(JSON-RPC)에 인증합니다.

★ 요청 핵심

SharpTalk가 요구하는 값

서버 URLurlhttps://my-odoo.example.com필수
데이터베이스db데이터베이스 이름필수
사용자명username로그인 이메일/아이디필수
API 키api_key개인 API 키 (비밀번호 대체)필수시크릿

SharpTalk는 이 4개 값으로 {url}/jsonrpc 에 common.authenticate(db, username, api_key) 를 호출해 검증합니다.

① 서버 URL

  1. Odoo에 접속하는 브라우저 주소의 호스트 부분입니다.Odoo Online(SaaS): https://회사이름.odoo.com · 자체 호스팅/Odoo.sh: 실제 도메인. 경로(/web 등)는 붙이지 마세요.

② 데이터베이스 이름  — 어디서 확인?

  1. Odoo Online(SaaS) — DB 이름 = 서브도메인. 회사이름.odoo.com 이면 DB는 회사이름 입니다.
  2. 자체 호스팅 — 로그인 화면의 데이터베이스 선택 드롭다운에 표시되는 이름입니다.드롭다운이 없으면(단일 DB): …/web/database/manager 목록의 이름, 또는 서버 실행 옵션 -d <db> / db_name 설정값.
  3. 회사명·표시이름이 아니라 실제 DB 식별자를 대소문자·하이픈까지 정확히 넣어야 합니다.

③ 사용자명

  1. Odoo 로그인 아이디(대부분 이메일). API는 이 사용자의 권한으로 동작하므로 주문·연락처·상품 조회 권한이 있는 전용 통합 계정을 권장합니다.

④ API 키  — Odoo 어디에서 발급?

  1. 우측 상단 아바타 → 내 프로필(My Profile / Preferences) 를 엽니다.
  2. 계정 보안(Account Security) 탭으로 이동합니다.항목이 안 보이면 설정 → 개발자 모드 활성화(Activate the developer mode)를 먼저 켜세요.
  3. API 키(Developer API Keys) → 새 API 키(New API Key) → 용도 이름 입력 → 비밀번호 확인 → 생성된 키를 즉시 복사합니다.이 키는 생성 직후 한 번만 표시됩니다. 외부 API 호출 시 비밀번호 대신 사용되니, 계정 비밀번호를 직접 넣지 말고 반드시 API 키를 사용하세요.
!테스트 성공 시 Connected (uid N) 이 표시됩니다. 실패 시 authentication failed — check db / user / API key 는 대개 DB 이름 오타가 원인입니다.

05Haravan

Admin API 액세스 토큰(Shopify 호환)으로 연결합니다.

Admin API · Bearer

SharpTalk가 요구하는 값

쇼핑몰 주소shop_domainyour-store.myharavan.com필수
액세스 토큰access_tokenAdmin API 액세스 토큰필수시크릿

Haravan 관리자에서 발급

  1. 쇼핑몰 주소 — Haravan 관리자 접속 주소 your-store.myharavan.com 입니다.
  2. 액세스 토큰 — 관리자 앱/개발(Apps) 영역에서 비공개 앱(Private App) 또는 Admin API 연동을 만들고 발급되는 토큰을 사용합니다.주문·고객·상품 읽기 권한을 부여하세요. Haravan Admin API는 Shopify 호환이라 SharpTalk는 …/admin/shop.json 을 Bearer 토큰으로 검증합니다.
  3. 발급된 토큰을 액세스 토큰 칸에 붙여넣고 저장 → 연결 테스트합니다. 401=토큰 무효·만료.
