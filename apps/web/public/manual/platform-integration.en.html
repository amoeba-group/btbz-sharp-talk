SharpTalk · Settings → Platforms

Commerce integrations: which value, and where to find it

A practical guide to the values you enter on /settings/platforms to connect each store — username, database name, API key and the rest — and where to issue or find each one in the platform's own admin. Prepare the values, pick the platform under Add a platform, paste them into its settings dialog, save, then verify with Test connection.

Screen layout (revised 2026-10-19) — /settings/platforms has two sections. Connected platforms shows a card only for platforms whose credential is saved; the badge is Connected (a test or sync succeeded), Error, or Not tested (saved only). Add a platform lists every supported platform as a button; ones already connected are ticked. If you run a platform of your own that is none of Shopify, Cafe24, WooCommerce, Odoo or Haravan, use the Own platform button and register just a name and a note (nothing to issue; it reads "Registered" at once).

Common to every platform

  • Secret values (tokens, secrets, API keys) are not shown again after saving — re-enter one only when you rotate it.
  • URLs must be https:// public domains. Internal or private addresses (localhost, LAN IPs) are blocked for security.
  • The minimum access needed is read orders, customers and products. Write access is never required.
  • When a connection test fails, the card shows the reason — 401 = token invalid/expired, 404 = wrong address.
  • The screen diagrams below are illustrations of where to issue each value; the real vendor screens may differ in wording and layout.

01Shopify

Add a platform → Shopify (or the connected card's Configure): enter the shop domain and Admin API token.

Admin API · custom-app token

What SharpTalk asks for

Shop domainshop_domainyour-store.myshopify.comrequired
Admin API access tokenaccess_tokenshpat_…requiredsecret
API key / secretapi_key · api_secretFor public (OAuth) apps — leave blank for a custom appoptional

Issue it in the Shopify admin

  1. Go to Settings → Apps and sales channels.
  2. Develop apps → Create an app, then name the app.
  3. Under Configuration → Admin API integration, grant the read scopes.read_orders · read_customers · read_fulfillments · read_products
  4. Click API credentials → Install app.
  5. Copy the Admin API access token (shpat_…) shown right after install.The token is shown only once — save it to SharpTalk immediately.
  6. The shop domain is the xxxx.myshopify.com part of the admin URL (not your branded domain).
↔If you already installed via SharpTalk's public-app "Connect" button, the token is stored automatically. The manual entry above is for a custom app you run yourself.

02Cafe24

Connect a Cafe24 store with an Admin API v2 OAuth access token.

A mall connected through OAuth is tested, synced (orders · catalogue) and opened from the Cafe24 card under Connected platforms; Configure re-runs the consent (2026-10-19). The card’s connection test mints a real access token and reads one product (or order).

Admin API v2 · Bearer (OAuth)

What SharpTalk asks for

Mall IDmall_idStore ID (e.g. yourmall)required
Access tokenaccess_tokenAdmin API OAuth tokenrequiredsecret
Client ID / Secretclient_id · client_secretDeveloper-center app values (for token auto-refresh)optional

Find it in the Cafe24 Developer Center

  1. Mall ID — the yourmall part of the admin URL yourmall.cafe24.com, or the store ID shown at the top of the admin.
  2. Client ID / Secret — sign in to developers.cafe24.com → Create app → find them under the app's App info.Add read scopes to the app — mall.read_order · mall.read_customer · mall.read_product.
  3. Access token — paste the Admin API token issued through the OAuth flow (Authorization Code → Access Token).Valid for 2 hours; the refresh token lasts 14 days — re-issue when it expires.
↔The Cafe24 OAuth "Connect" button at the top of Settings connects in one click with the mall's owner account and manages the token for you. Prefer it if manual token entry is a hassle.

03WooCommerce

Connect with a REST API v3 consumer key/secret (Basic auth).

REST v3 · Basic auth

What SharpTalk asks for

Store URLstore_urlhttps://store.example.comrequired
Consumer keyconsumer_keyck_…requiredsecret
Consumer secretconsumer_secretcs_…requiredsecret

Issue it in the WordPress · WooCommerce admin

  1. Go to WooCommerce → Settings → Advanced → REST API.
  2. Click Add key.
  3. Enter a description, choose the User, and set Permissions to Read.
  4. Generate API key → the Consumer key (ck_…) and Consumer secret (cs_…) appear.You can't see them again after leaving this screen — copy them now.
  5. The Store URL is the site's top-level address. Don't append /wp-admin or /wp-json.
!The connection test calls …/wp-json/wc/v3/system_status. 404 = REST API disabled or wrong URL (check permalinks), 401 = key/secret mismatch.

04Odoo

Authenticate to the external API (JSON-RPC) with URL · DB · user · API key.

★ key request

What SharpTalk asks for

Server URLurlhttps://my-odoo.example.comrequired
DatabasedbDatabase namerequired
UsernameusernameLogin email / IDrequired
API keyapi_keyPersonal API key (replaces the password)requiredsecret

SharpTalk verifies these four values by calling common.authenticate(db, username, api_key) at {url}/jsonrpc.

① Server URL

  1. The host part of the address you open Odoo at.Odoo Online (SaaS): https://mycompany.odoo.com · Self-hosted / Odoo.sh: your real domain. Don't append a path such as /web.

② Database name  — where to find it

  1. Odoo Online (SaaS) — the DB name = the subdomain. For mycompany.odoo.com the DB is mycompany.
  2. Self-hosted — the name shown in the database dropdown on the login screen.If there's no dropdown (single DB): the name listed at …/web/database/manager, or the server's -d <db> / db_name setting.
  3. Enter the actual DB identifier exactly (case and hyphens included), not the company or display name.

③ Username

  1. Your Odoo login ID (usually an email). The API acts with this user's rights, so use a dedicated integration account with read access to orders, contacts and products.

④ API key  — where to issue it in Odoo

  1. Open the avatar → My Profile / Preferences at the top right.
  2. Go to the Account Security tab.If it isn't there, first turn on Settings → Activate the developer mode.
  3. Developer API Keys → New API Key → name its purpose → confirm your password → copy the generated key immediately.The key is shown only once. It replaces your password for external API calls, so use the API key — never your account password.
!On success the card shows Connected (uid N). A failing authentication failed — check db / user / API key is usually a typo in the DB name.

05Haravan

Connect with an Admin API access token (Shopify-compatible).

Admin API · Bearer

What SharpTalk asks for

Shop domainshop_domainyour-store.myharavan.comrequired
Access tokenaccess_tokenAdmin API access tokenrequiredsecret

Issue it in the Haravan admin

  1. Shop domain — your Haravan admin address your-store.myharavan.com.
  2. Access token — create a Private App or Admin API integration under Apps in the admin and use the token it issues.Grant read access to orders, customers and products. Haravan's Admin API is Shopify-compatible, so SharpTalk verifies it against …/admin/shop.json with the Bearer token.
  3. Paste the token into the Access token field, save, and test. 401 = token invalid/expired.
