# Go2Joy 노션 지식 연동 설정 가이드

- 대상: Go2Joy 노션 워크스페이스 관리자 (통합 "HA-UserGuide" 소유자)
- 기준일: 2026-10-19 (스테이징 실측)
- 이전 안내(2026-08-28, 통합 "Truc connection" 기준)는 10/16 토큰 교체로 내용이 바뀌어 이 문서로 대체합니다.

> 노션 페이지를 SharpTalk 상담 AI의 지식으로 쓰려면 Go2Joy 노션 관리자가 해야 할 일을 정리했습니다. 작업은 노션 화면에서만 하며, 페이지당 1분이면 됩니다.

## 1. 현재 상태

SharpTalk 쪽 설정은 모두 정상입니다. 토큰은 유효하고, 통합의 정체와 접근 범위를 Notion API로 직접 확인했습니다.

| 항목 | 확인 결과 |
|---|---|
| 등록된 통합 | **HA-UserGuide** (10/16 교체) |
| 통합이 속한 워크스페이스 | **Go2Joy** |
| 통합이 볼 수 있는 페이지 | **1건뿐** — "Hướng dẫn sử dụng Hotel Admin" (ID `bfb56ba4…`) |

SharpTalk에 등록된 노션 소스 3건은 전부 동기화 실패 상태이며 원인은 모두 같습니다. **해당 페이지가 "HA-UserGuide" 통합에 연결(Connections)되어 있지 않습니다.**

| # | SharpTalk 소스 이름 | 등록된 노션 대상 | 상태 |
|---|---|---|---|
| 1 | Go2Joy Hotel FAQ (Notion) | `hotel-go2joy.notion.site/FAQ-f03737634c38…` | ❌ 미연결 |
| 2 | Hướng dẫn sử dụng Hotel Admin | `…8968fee0bb548347a35e01756b4cc89c` | ❌ 미연결 (통합에는 같은 제목의 다른 ID `bfb56ba4…`만 보임 — 2-D 참고) |
| 3 | Hướng dẫn đăng ký khách sạn trên Go2Joy | `…2026dfbd464d800085cedea4c57f8d15` | ❌ 미연결 |

## 2. Go2Joy에서 해야 할 작업

### A. 페이지 3건을 통합에 연결 (페이지당 약 1분)

아래 3개 페이지 각각에서:

1. 노션에서 페이지를 엽니다.
2. 우측 상단 **⋯**(더보기) → 아래쪽 **연결(Connections)**.
3. 검색란에 **HA-UserGuide** 입력 → 선택 → 액세스 허용 **확인**.
4. **⋯ → 연결** 목록에 "HA-UserGuide"가 보이면 완료.

대상 페이지:

- **Go2Joy Hotel FAQ** — `https://hotel-go2joy.notion.site/FAQ-f03737634c3848339910d50f7e77bf7b`
- **Hướng dẫn sử dụng Hotel Admin** — ID `8968fee0bb548347a35e01756b4cc89c` (2-D 참고)
- **Hướng dẫn đăng ký khách sạn trên Go2Joy** — ID `2026dfbd464d800085cedea4c57f8d15`

**하위 페이지는 자동 상속됩니다.** 상위 페이지 1곳만 연결하면 그 아래 페이지는 따로 연결할 필요가 없습니다.

### B. "웹에 공개"는 연결이 아닙니다

FAQ 페이지는 `hotel-go2joy.notion.site` 주소로 웹에 공개(Publish)되어 있습니다. 공개 페이지는 브라우저로는 누구나 볼 수 있지만, **Notion API는 공개 여부와 무관하게 "통합에 연결된 페이지"만 읽을 수 있습니다.** 공개 페이지라도 A의 연결 작업이 반드시 필요합니다.

### C. 워크스페이스 확인

통합 "HA-UserGuide"는 **Go2Joy 워크스페이스**에 설치되어 있습니다. 3개 페이지가 모두 이 워크스페이스 안에 있어야 연결 목록에 "HA-UserGuide"가 나타납니다. 검색해도 나오지 않으면 그 페이지는 다른 워크스페이스에 있는 것입니다. 페이지를 Go2Joy 워크스페이스로 옮기거나, 그 워크스페이스에 통합을 새로 만들고 토큰을 SharpTalk에 다시 등록해야 합니다(E 주의).

### D. "Hướng dẫn sử dụng Hotel Admin" — 어느 페이지가 맞는지 확인

SharpTalk에 등록된 ID는 `8968fee0…`인데, 현재 통합에 연결된 페이지는 같은 제목의 `bfb56ba4…`입니다. 둘 중 하나입니다.

- 페이지가 복제·이동되어 ID가 바뀜 → `bfb56ba4…`가 최신본이면 알려주세요. SharpTalk 쪽에서 대상 ID를 바꿉니다(Go2Joy 작업 없음).
- 두 페이지가 별개 → `8968fee0…` 페이지도 A대로 연결해 주세요.

확인 방법: 노션에서 그 페이지를 열고 브라우저 주소창 끝의 32자리 영숫자를 봅니다.

### E. 토큰(통합)을 바꿀 때 주의

10/16에 통합이 "Truc connection"에서 "HA-UserGuide"로 바뀌면서 **이전 통합에 연결해 둔 페이지는 전부 새 통합에서 보이지 않게 되었습니다.** 연결은 통합별로 따로 관리되기 때문입니다. 앞으로 토큰을 교체할 일이 있으면:

1. 새 통합을 만들고,
2. SharpTalk 소스로 쓰는 **모든 페이지에 새 통합을 다시 연결**한 뒤,
3. SharpTalk 콘솔에 새 토큰을 등록합니다.

가능하면 토큰은 바꾸지 말고 유지하는 것이 가장 안전합니다.

## 3. 연결 후 확인 — Go2Joy가 직접 할 수 있습니다

1. SharpTalk 콘솔 → **지식** → **소스** 표 → 해당 소스 행의 **↻**(동기화) 클릭.
2. 성공하면 초록 알림과 함께 소스 행에 마지막 동기화 시각이 검정으로 표시됩니다.
3. 실패하면 빨간 알림이 원인과 조치 방법을 그대로 보여줍니다. 아래 메시지가 나오면 A가 아직 안 된 것입니다.
4. 동기화 성공 후 챗 위젯에서 해당 내용을 질문하면 답변 근거로 인용됩니다.

실패 알림 예:

```
소스 대상에 접근할 수 없습니다.
Could not find page with ID: f0373763-… Make sure the relevant pages and databases are shared with your integration "HA-UserGuide".
노션 페이지가 통합에 공유되지 않았습니다 — 노션에서 페이지 ⋯ → 연결(Connections)에 통합을 추가하세요.
```

성공 알림 예: `동기화: 생성 1건, 갱신 0건`

## 4. 수집 범위와 제약

| 항목 | 내용 |
|---|---|
| 수집 범위 | 대상 페이지 본문 + 바로 아래 1단계 하위 페이지. 더 깊은 중첩은 수집되지 않습니다. |
| 텍스트만 | 문단·제목·리스트·토글·표·코드. 이미지·첨부·임베드는 제외. |
| 분량 | 1회 최대 200페이지, 페이지당 약 30,000자. 아주 긴 페이지는 하위 페이지로 나누는 것을 권장. |
| 수정 반영 | 노션 수정은 자동 반영되지 않습니다. 콘솔에서 ↻를 다시 클릭하면 변경분만 갱신됩니다. |
| 페이지 삭제 | 지식에서 삭제되지 않고 숨김 처리됩니다. |
| 보안 | 토큰은 암호화 저장, 읽기 전용. 연결한 페이지(와 하위)만 접근할 수 있습니다. |
