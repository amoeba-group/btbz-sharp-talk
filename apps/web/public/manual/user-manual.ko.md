## 1. 시작하기

### 1.1 콘솔 접속
- 테넌트 콘솔: `https://shoptalk.amoeba.site/user/<슬러그>` — 상점별 전용 로그인 주소입니다.
- 플랫폼 관리자: `/admin/login`.
- 로그인은 이메일 + 비밀번호(JWT). 초대 계정은 **임시 비밀번호**로 첫 로그인 후
  **강제 변경**(10자 이상·문자 종류 3종·흔한 비밀번호 금지)을 거칩니다.
- master/director와 시스템 관리자는 **MFA(TOTP)** 등록이 강제됩니다(시행일 전 유예
  배너 → 시행일 후 차단 모달). 등록 시 복구 코드 10개가 **한 번만** 표시됩니다.
- 온보딩 절차 전체: [간단 세팅 매뉴얼 1~2장](quick-setup.ko.md).

### 1.2 역할·권한 (RBAC)
- **직급(rank)**: master · director · manager · staff / **직무 라벨**: consult(상담) ·
  accounting(정산) · operations(운영). 시스템 관리자: super · admin.
- 메뉴 노출은 **2계층**: ① 플랫폼 관리자가 테넌트에 제공하는 메뉴(요금제 기본 +
  예외) → ② 테넌트 master가 정하는 직급별 권한 + 사용자별 예외([설정]의 *메뉴 접근
  권한* 카드). URL 직접 입력도 서버가 재검증해 차단합니다.
- 소유자 가시성 정책(ACL)이 기능 권한 위에 추가로 적용됩니다.

### 1.3 콘솔 메뉴
사이드바 로고를 클릭하면 **접근 가능한 화면 카드 목록**(`/menu`)이 열립니다.

## 2. 고객 위젯

### 2.1 화면 구성
- 쇼핑몰 페이지의 **런처**(위치·크기·아이콘은 테넌트 테마 설정) → 클릭 시 패널
  (모바일 전체 화면 / 데스크톱 플로팅 카드).
- 헤더: 상점 표시 이름(또는 로고), **언어 전환**(en/es/ko/vi/ja/zh 6종 — 전환 시
  세션 언어도 서버에 반영되어 AI 답변 언어가 바뀜), 환경설정(톱니), 닫기.
- **탭**: 알림 / 주문 / 채팅 — 어떤 탭을 어떤 순서·위치(상단/하단)로 보일지는 테넌트
  설정을 따릅니다. 탭이 1개뿐이면 탭 바 자체가 숨습니다.

### 2.2 알림·주문 탭
- 알림 탭 칩: `전체 · 이벤트` / 주문 탭 칩: `주문(주문 목록) · 배송 · 리뷰 · 문의`.
  **한쪽 탭을 끄면 그 칩들이 남은 탭으로 흡수**됩니다 — 탭을 꺼도 기능은 사라지지
  않습니다.
- 항목: 아이콘·제목·상태 배지·본문·상대 시각·안읽음 점. 최신 안읽음 1건이 강조됩니다.
- **주문 상세**: 품목·합계·배송 추적 스테퍼·**배송조회**·**이 주문 문의하기**(주문번호를
  채팅으로 연계)·품목별 **리뷰 쓰기**(별점 1~5 + 후기).
- 인라인 주문 목록은 최근 구간만 보여주며, "더 보기"는 쇼핑몰 자체 마이페이지로
  연결됩니다(Cafe24는 주문 목록 페이지, 그 외는 계정 페이지).

### 2.3 채팅 탭
- 상단: **AI 상담 고지** + **상담 종료** 링크(진행 중일 때만).
- **동의 배너**: 최초 진입 또는 고지 버전 변경 시 표시. 동의 전에는 개인정보가 필요한
  기능이 제한됩니다.
- **시나리오 버튼**: 테넌트가 구성한 빠른 메뉴(기본 6종). 상품 도움말은 서브메뉴
  (사용법·성분·교환/반품·재입고)를 엽니다. 답변 뒤 빠른 칩(내 주문/배송/반품/상담원
  연결)이 붙습니다.
- **본인확인(AuthGate)** 2방식: ① 스토어 로그인 — 테넌트 설정에 따라 리다이렉트(기본)
  또는 팝업, Cafe24/Shopify 로그인 경로 자동 처리, 복귀 시 위젯 자동 재오픈 ② 비회원
  주문조회 — 주문번호+이메일 (횟수 제한 있음).
- **첨부**: 이미지 ≤10MB(HEIC 포함 — 자동 변환) / 파일 ≤20MB(pdf·txt·csv·docx·xlsx),
  메시지당 최대 5개. 파일만 보내는 것도 가능합니다.
- **상담카테고리 선택**: 테넌트가 고객에게 노출한 상담카테고리가 있으면, 고객이 [상담원
  연결]을 누를 때 "어떤 상담이 필요하세요?" 카드가 먼저 뜨고 고른 상담카테고리의 담당
  그룹으로 연결됩니다. AI가 상담원에게 넘길 때도 안내 아래에 같은 카드가 떠서 고르면 그
  담당 그룹으로 다시 연결됩니다(아무도 수락하지 않은 동안 첫 선택 1회). [건너뛰기]를
  누르면 기존처럼 연결됩니다. 노출된 상담카테고리가 없으면 카드 없이 바로 연결합니다(§14.1).
- **대기 표시** 3종: AI 생성 중 / 상담원 응대 중 / 인계 대기(아직 상담원 미배정).
- **종료·만족도**: 고객이 종료하면 확인 후 종료 표시. 종료된 대화에는 24시간 안에
  **만족도(이모지 5단계 = 1~5점)** 카드가 표시됩니다. 새 메시지를 보내면 새 상담이
  시작됩니다.

### 2.4 환경설정(톱니)
- **동의 관리**: 상태·일시·버전 확인, 철회(2단계 확인 — 철회 시 상담 중단), 재동의.
- 로그인 후: **마케팅 수신 거부**(단일 토글 — 프로모션·쿠폰·리뷰 요청 거부; 주문·배송
  알림은 무관하게 발송), **판매·공유 거부**(CCPA/CPRA), **내 데이터 내보내기**(JSON
  다운로드), **내 데이터 삭제**(2단계 확인 — 완료 시 위젯이 로그아웃 상태로 초기화).
- 카테고리×채널 수신 매트릭스는 위젯에서 제거되고 **상점 정책(콘솔 알림 채널 설정)**
  으로 이관되었습니다.

## 3. AI 응답 흐름 (요약)

```
고객 메시지 → 의도 분류(개인정보 필요 시 본인확인 안내)
  → 정책 강제 핸드오프(deny-list) 매칭 시:
      「답변 안 함」 규칙 → AI 없이 즉시 상담원 인계
      「답변 후 인계」 규칙 → 지식으로 먼저 답한 뒤 그대로 인계
  → 지식 검색(RAG) → 답변 생성(페르소나+규칙, 신뢰도 산정) → 모더레이션
  → 신뢰도 충분: 고객에게 답변+출처 / 부족·차단·고객요청: 상담원 대기열
```

- 상담원 발신 메시지도 모더레이션을 동일하게 통과합니다(우회 불가, 실패 시 차단).
- 파이프라인의 각 지점을 조정하는 방법: [지식·AI 매뉴얼](knowledge-ai.ko.md).

## 4. 라이브챗 콘솔
*(`/live-chat` · consult 라벨 보유자)*

3열 구성: **대기열(좌) — 대화(중) — 컨텍스트(우)**. 목록은 5초 간격 자동 갱신됩니다.

### 4.1 대기열(좌)
- 범위: **전체 / 상담 필요 / 종료** (기본 전체 — AI가 응대 중인 대화도 보입니다).
  두 번째 줄의 **그룹** 탭은 세션 그룹핑(§4.5)입니다.
- 채널 필터 + **AI 에이전트 필터**(전체 에이전트/에이전트별). 고객명/이메일 검색.
  채널: 위젯·텔레그램·바이버·잘로·라인·왓츠앱·위챗·카카오톡·SMS·이메일 — btbz 릴레이로
  들어온 대화도 원래 메신저 이름으로 표시됩니다. **SMS는 수신 전용** 배지가 붙고 답장이
  비활성화됩니다.
- 각 행: **세션 별칭**(상담원이 인라인으로 수정 가능, 미설정 시 고객명→이메일→세션ID),
  채널·상태 배지, 배정 AI 에이전트 칩, "자동응답 OFF" 칩, 마지막 메시지, 경과 시간.
- **핀**: 행에 마우스를 올리면 핀 아이콘이 나타납니다. 핀 대화는 항상 목록 최상단이며,
  **팀 공유·스토어당 최대 3개**(4번째는 거부 — 기존 핀을 먼저 해제).
- 필터·검색 줄은 스크롤해도 상단에 고정되고, 3개 패널의 내부 영역만 각각 스크롤됩니다.

### 4.2 대화(중)
- 헤더의 **자동응답 제어**: `채널 기본 따름 / 자동 / 승인 후 발송 / 끄기` + 현재 상태
  배지(AI 응답 중 / 상담원 응답 / 승인 대기). 상담원이 인수한 대화는 이 설정과 무관하게
  상담원 응대가 우선합니다.
- 버튼: **[접수]**(인수 — 담당 지정), **[AI에 반환]**(상담원 상태에서만 — 대화를 다시
  AI에게 맡김, 확인 모달), **[종료]**, **[동기화]**(수동 새로고침), **[핀 고정/해제]**,
  **[지정]**(담당을 다른 AI 에이전트/상담원으로 변경 — AI 에이전트 변경은 **다음 응답부터**
  적용).
- **고객 메시지 액션 4종** — 고객 말풍선에 마우스를 올리면 나타납니다(AI가 자동 응답
  중인 대화에서는 숨김):
  | 액션 | 동작 |
  |---|---|
  | 번역 | 언어 선택 → 원문 아래에 **콘솔 전용** 번역 말풍선(고객에게는 안 보임) |
  | 지식 조회 | 메시지 내용을 우측 지식 조회 패널로 복사해 바로 질의 |
  | 답글 달기 | 인용 칩을 작성창 위에 표시 — 발송 시 인용문이 함께 조립됨 |
  | 이 메시지를 이슈로 등록 | 발췌+유형+메모로 이슈 생성(이 대화에 이슈가 이미 있으면 메모로 추가) |
- **승인 후 발송 모드**: AI 초안이 편집 가능한 패널로 뜨고(신뢰도 표시), **[승인 발송]**
  하면 상담원 명의로 나갑니다(모더레이션·감사 동일 적용). [폐기]도 가능.
- **메시지 작성**: 텍스트 + 첨부(고객 위젯과 동일 한도 — 이미지 10MB/파일 20MB/최대
  5개). 전송이 거부되면 모더레이션 차단입니다 — 표현을 바꿔 재시도. **SMS 채널은
  수신 전용**이라 작성이 비활성화됩니다.
- AI 답변 말풍선 아래 **[이 답변을 지식으로]**(master/director만): 답변을 지식 문서
  초안으로 캡처합니다.
- 과거 메시지는 "이전 대화 더 보기"로 로드합니다.

### 4.3 컨텍스트(우)
- **AI 브리핑**: 지금까지의 대화 요약·의도·감정·권장 조치. (그룹을 선택하면 이 자리가
  **고객여정분석** 패널로 바뀝니다 — §4.5)
- **지식 조회**: 대화 중 지식에 직접 질문(마지막 고객 메시지 원클릭 사용) → 답변·출처
  (stale/충돌 배지, 문서 바로가기) 확인 → **[고객에게 전송] / 수정 후 전송 / [지식으로 제안]**(지식 담당자 승인 대기로 등록).
- **고객 카드**: 이름·이메일·전화·등급 + **고객 매칭**(검색 연결) / **고객 생성**.
- **최근 주문** 카드.
- **이슈 패널**(네이티브 워크플로우 테넌트): 이슈 번호·상태·유형·재오픈 수, [해결]/
  [반려] (사유 필수: 정책상 불가/오배정/스팸), 담당 재배정 선택, 이벤트 타임라인.

### 4.4 인계 알림·알람센터·자동 마무리
- **에스컬레이션 알람**: 새 인계가 생기면 콘솔 어디에 있든 10초 안에 알림 팝업이 뜹니다.
  팝업에는 사유(낮은 신뢰도/모더레이션 차단/고객 요청/상담카테고리 선택으로 재연결)와
  함께 **호텔·권역·상담카테고리**, **배정: 상담원 이름**(맞는 규칙이 없으면 "전체"),
  **규칙 이름**이 표시됩니다. 알람은 같은 테넌트의 상담원 모두에게 보이며, 다른 상담원에게
  배정된 것에는 *다른 상담원 배정* 표시가 붙습니다.
  - **[닫기]**: 내 화면에서만 숨깁니다(읽음). 배정자의 알람·재알림은 그대로입니다.
  - **[상담 열기]**: 대화로 이동합니다. 내가 배정자이거나 전원 대상 알람이면 **확인 처리**
    (재알림 중지)됩니다.
- **헤더 🔔**: 읽지 않은 알람 수. 누르면 최근 알람 20건(읽음 여부·배정·상태·확인자)이
  열리고, *전체 보기*로 **알람센터**(`/live-chat/alerts`)에 갑니다.
- **알람센터**: 전체 / 내 배정 / 전원 대상, 상태(미확인·확인됨), 기간(1·7·30·90일),
  상담카테고리로 걸러 봅니다. 행을 누르면 대화로 이동하고, 확인할 수 있는 알람에는
  [확인 처리]가 있습니다.
- **알람 설정(개인)**: 🔔 드로어나 알람센터의 *알람 설정* — 팝업(모든 알람 / 내게
  배정된 것만(전원 대상 포함) / 끄기), 소리(들어보기), 브라우저 데스크톱 알림(브라우저
  권한 필요), 내게 배정되면 메일 받기. 팝업을 꺼도 🔔와 알람센터에는 모두 남습니다.
- 라이브챗 대화 헤더에는 고객이 고른 상담카테고리가 `상담: 결제` 배지로 표시되고,
  대화 중에 시스템 줄로도 남습니다.
- **방치 대화 자동 마무리**(서버 동작, 위젯 채널만): 양쪽 모두 30분 무응답이면 "더
  도와드릴 일이 있을까요?"를 보내고, 1분 내 무응답이면 종료합니다. 7일 넘은 대화는
  조용히 종료됩니다. 이메일 회신 대기 대화는 자동 종료하지 않습니다.

### 4.5 세션 그룹핑·고객여정분석
- 목록 헤더의 **[선택]** → 세션을 2개 이상 체크 → **[그룹으로 묶기]**. 유형 2종:
  **타임라인**(한 고객의 여러 세션을 시간순으로) / **프로젝트**(같은 건에 얽힌 여러
  당사자의 대화). 새 그룹을 만들거나 기존 그룹에 추가할 수 있습니다.
- **그룹 룸**(대기열의 *그룹* 탭에서 진입): 멤버 세션 전체를 하나의 타임라인으로
  봅니다. 발신은 **1:1** — 먼저 **수신 대상**을 지정해야 전송됩니다. 설정에서 멤버
  제거·**그룹 해제**가 가능하며, 해제해도 대화와 메시지는 그대로 남습니다.
- **고객여정분석**(그룹 선택 시 우측 패널): **[리포트 생성]**(기간 전체/지정) →
  ① 요약 ② 접촉 이력 ③ 무엇을 묻는가 ④ 해결 소요시간 ⑤ 관계 단계(5A) ⑥ 욕구
  단계(가설) ⑦ 다음 행동. **수치는 코드가 세고 서술만 AI가 씁니다** — 그룹이 크면
  수십 초 걸리며 화면을 떠나도 됩니다. 지난 리포트 2개를 골라 **심화분석**(비교)도
  가능합니다(작성 기준 버전이 다르면 경고 표시).
- 리포트의 **작성 기준**(절 on/off·상위 질문 수·샘플 상한·인용 길이·금지 표현)은
  [테넌트 설정 → 기타 설정]의 *여정분석 작성 기준*(master 전용)에서 관리합니다.
  저장하면 새 버전이 되고, 기존 리포트는 그 시점 버전으로 유지됩니다.

## 8. 통계
*(`/statistics` · 기간 필터 공통, 기본 최근 30일)*

상단 섹션 6개 — **질문 분석 / 채널 / 상담원 / 처리 / 만족도 / 시간대**.

- **질문 분석**: 하위 탭 4개(**의도 / 사용된 지식 / 키워드 / 유사질문 그룹**).
  추이 차트 + 표(건수·비중·**이관율**·**근거 없음**·**평균 신뢰도**). ⚠ 표시 행은
  이관율이 높거나 신뢰도가 낮은 것 — **지식 보강 우선순위 목록**입니다(*사용된 지식*
  탭에서는 행 클릭으로 해당 문서로 이동). 일별 스냅샷 기준이라 대화 로그가 삭제돼도
  유지되며, 집계가 이틀 이상 멈추면 상단에 경고 배너가 뜹니다.
- **채널**: 경로별 대화 수·고객 메시지·**대화당 메시지(중앙값)**·상담원 인계.
  중앙값을 먼저 보세요 — 수백 턴짜리 대화 하나가 평균을 크게 왜곡합니다.
- **상담원**: **AI 에이전트** 표와 **사람 상담원** 표. 대화 수·보낸 답변·해결·만족도
  (평가 건수가 함께 표시됩니다 — 표본이 얇으면 신중히 해석).
- **처리**: 종료된 대화가 끝난 방식. 해결(고객이 평가함 / 상담원이 종료 / 확인 후
  종료) vs 미해결(진행 중 / 종료 처리 없이 끝남 / **고객이 마지막 발화**). 고객여정
  리포트·대시보드와 **같은 정의**입니다 — 고객이 마지막으로 말한 대화는 질문이 남은
  것이므로 해결로 세지 않습니다.
- **만족도**: 평균 평점·응답 수·응답률·1~5 분포 + **상담원별 / 세션별** 표(평점·상담원
  필터).
- **시간대**: 요일×시간 그리드(고객 메시지 기준) — **테넌트 시간대 기준**이며,
  시간대 미설정 시 UTC로 계산된다는 경고가 표시됩니다.

채널·상담원·처리·시간대 섹션은 대화 로그에서 직접 계산하므로 **보존기간을 넘는
과거는 조회되지 않습니다**(질문 분석·만족도는 스냅샷이라 유지).

에 정리되어 있습니다. 화면별 심화 설명은 AI-SETTINGS-GUIDE 참조.

핵심만 요약:
- AI는 **활성 지식 문서에서만** 답합니다. 인계가 잦으면 지식 부족이 원인입니다.
- 지식은 **Smart Knowledge Board**(`/knowledge/board`)에서 먼저 작성·검토한 뒤 KB로
  **채택**하는 것이 표준 경로입니다(시뮬레이션으로 채택 전 효과 확인). 문서 직접
  추가는 긴급 수정용입니다.
- 지식 그룹 3종(CounselInfo 상담 / ProductInfo 상품 / OperationInfo 운영) × 카테고리로
  분류하며, 카테고리의 **에이전트 범위**로 특정 AI 에이전트에게만 보이게 할 수 있습니다.
- 일괄 도구: **일괄 다운로드 ↔ 일괄등록**(CSV/XLSX 라운드트립), **AI 임포트**
  (pdf·docx·xlsx·csv·md·YouTube 자막 → 초안 검토 → 보드 게시).
- 모든 발신(AI·상담원)은 모더레이션을 통과합니다. 오류 시 안전하게 **차단**됩니다.
- AI 코칭·설정 변경은 **승인 게이트**를 거칩니다 — 제안을 검토 후 적용하세요.

## 14. 테넌트 설정

`/settings`는 **8개 탭**입니다(구 단일 "환경설정" 화면 → 2026-08-24 7개 탭 → 2026-10-24
*상담원 연결* 탭 분리). 탭도 제공 메뉴 단위라, 플랫폼 관리자가 제공하지 않은 탭은 보이지
않습니다(*상담원 연결* 탭은 *기본 설정*과 같은 제공 단위).

| 탭 | 내용 |
|---|---|
| 기본 설정 | **AI 엔진**(테넌트 자체 엔진 등록 — 플랫폼 엔진보다 우선 사용, 연결 테스트·기본값 지정. 내 키 호출은 우리 계정으로 청구) · **AI 사용량**(기간·축별 호출/토큰 집계, stub 폴백 경고 — 금액은 추정하지 않음) · 스토어프론트 · **지식 옵션**(지식 페이지의 "사용 가이드" 카드 노출 여부 — 쇼핑몰형 테넌트용, 기본 꺼짐) |
| 상담원 연결 | 담당 상담원 · **배정 규칙**(상담카테고리 × 업무 × 고객 정보 → 상담원 그룹, **배정 확인**·경고, **상담카테고리 관리**) · 미수락 재알림 · 근무시간·휴게시간 · 영업외 이메일/문구 · SLA · 정책 강제 핸드오프 (§14.1) |
| 위젯 설정 | 위젯 테마(브랜드 색·헤더·로고·런처 위치) · **커스텀 위젯**(폰트·글자 크기·모서리·패널 크기·런처 아이콘을 담은 디자인을 여러 개 만들어 보관하고 **[사용함]**으로 하나를 적용 — 배포 없이 즉시 반영, **[기본 위젯으로 복귀]**, 미리보기 링크, 복제, JSON **패키지 내보내기/가져오기**, **이력**(저장할 때마다 이전 상태를 남겨 복원), 보관·삭제. 정제 CSS 입력란은 플랫폼 관리자가 애드온을 허용한 테넌트에만 표시) · **디자인 파일**(폰트 woff2/ttf/otf·아이콘·이미지·시안 문서를 테넌트 전용 폴더에 업로드 — 배포와 무관하게 유지, 영역별 용량 표시) · 탭 구성 · 동작(표시 이름·인사말 — **6개 언어 탭**, 기본 문구가 함께 표시됨) · 임베드/SDK · 스토어 설치 가이드 — 상세: [커스텀 위젯 만들기 매뉴얼](custom-widget.ko.md) |
| 플랫폼 연동 | Shopify · Cafe24 · WooCommerce · Odoo · Haravan 타일 + 우상단 **[연동 가이드]**(자격증명 찾는 법 매뉴얼) |
| 마케팅·헬프데스크 | Klaviyo · Yotpo · Gorgias |
| 메신저 채널 | 텔레그램 · 바이버 · 아메바톡 허브 · btbz 메신저 릴레이 · 지메일 (잘로·라인·와츠앱은 지원 예정) |
| 기타 설정 | 알림 채널 · 메뉴 접근권한(master) · 여정분석 작성 기준(master, §4.5) · 저장된 연동 자격증명 · **설정 스냅샷**(위젯 테마·문구·탭·알림 등 12개 설정 필드와 커스텀 위젯 라이브러리를 JSON 한 파일로 저장 — 비교 후 복원·다운로드·삭제, 자격증명·시크릿은 포함하지 않음) |
| 개인정보 안내 | 처리방침 URL · 동의 안내 버전 (§15) |

- **저장 ≠ 연결**: 자격증명을 저장하면 상태가 "미테스트"입니다. **[연결 테스트]**를
  통과해야 "연결됨"(실패 시 "오류")이 되며, 대시보드의 연동 배지도 이 상태를 따릅니다.
- Odoo·WooCommerce·Haravan은 설정 모달의 **[상품 가져오기] / [주문 동기화]**로 데이터를
  가져옵니다(Cafe24는 전용 OAuth 카드, Shopify는 [지금 동기화]+[웹훅 등록]). 가져온
  상품을 AI가 쓰려면 [지식]의 카탈로그 동기화가 별도로 필요합니다(§10.3).
- **정책 강제 핸드오프(deny-list)** 규칙에는 "고객에게 보이는 방식" 2종이 있습니다:
  **답변 안 함**(AI 없이 즉시 인계, 기본) / **답변 후 인계**(지식으로 먼저 답한 뒤
  인계) — 어느 쪽이든 상담원은 호출됩니다.
### 14.1 상담원 연결 — 상담카테고리와 배정 규칙

**상담카테고리**는 고객이 위젯에서 고르는 상담 주제입니다(예: 예약·결제·객실 등록).
배정 규칙 머리글의 **[상담카테고리 관리]**에서 관리합니다.
- 코드(영문·숫자·_)와 이름으로 추가합니다. **코드는 만든 뒤 바꿀 수 없고**, 이름·순서는
  언제든 바꿀 수 있습니다.
- **노출함/노출 안 함**: 노출함인 것만 위젯 카드에 보입니다(새로 만들면 노출함이 기본).
- **언어별 이름**(▸ 펼침): 고객 언어의 이름이 있으면 그것을, 없으면 기본 이름을 보여줍니다.
- 규칙·팀·라벨이 쓰고 있는 상담카테고리는 삭제할 수 없고, 어디서 쓰는지 안내합니다.
- 규칙 칩의 👁 표시는 고객에게 노출되는 상담카테고리라는 뜻입니다.

**배정 규칙**은 위에서부터 확인해 **상담카테고리 · 업무 · 고객 정보가 모두 맞는 첫 규칙**의
**상담원 그룹(팀 × 라벨)**과 개인 지정 상담원에게 연결합니다. 맞는 규칙이 없으면 담당
상담원에게, 담당 상담원도 없으면 전원에게 알립니다.
- **상담카테고리** 줄: 고객이 고른 값과만 비교합니다. 고르지 않은 고객에게는 상담카테고리를
  비운 규칙만 맞습니다.
- **업무** 줄: 질문 키워드와, *정책 강제 핸드오프(deny)* 규칙이 붙인 라벨을 봅니다. 업무
  줄의 라벨 칩은 정책 규칙으로 넘어온 대화에만 맞으니, 상담원 그룹 라벨은 아래 *담당자*에서
  고르세요.
- **고객 정보** 줄: 권역(북부·중북부·중부·중남부·남부 — 호스트 앱이 서명해 보낸 호텔 권역),
  지역(성), 언어, 인증 수준, 고객 등급·유형, 호텔, 역할, 방문 경로.
- 예: *결제 · 남부* = 상담카테고리 결제 + 권역 남부·중남부 → 팀 South × 라벨 회계.
- 고객이 상담카테고리를 고르면 직전 상담원 우선 연결 대신 그 상담카테고리의 규칙을 따릅니다.

**배정 확인**: 규칙 위 상자에 상담카테고리·권역·성·언어를 넣고 [확인]을 누르면, **저장하기
전 편집 중인 규칙**으로 누구에게 연결되는지와 건너뛴 규칙의 이유(상담카테고리 불일치·권역
조건 불일치·배정 가능 0명 등)를 보여줍니다. 알림은 보내지 않습니다.

**경고**(저장은 막지 않음): ① 업무 라벨 오용 ② 이름에 지역명이 있지만 권역·성 조건 없음
③ 지금 배정 가능한 상담원 0명(초대 수락 전 인원 표시). 초대를 수락하지 않은 사용자는
배정되지 않습니다.

  테넌트 폴더(디자인 파일·스냅샷)가 차지하는 용량입니다.

## 17. FAQ / 문제 해결

**Q. 봇이 계속 상담원에게 넘깁니다.**
지식 부족이 가장 흔한 원인입니다. 통계(`/statistics`)의 ⚠ 행과 지식 QA 패널로 원인을
확인하고 문서를 보강하세요. deny-list(정책 강제 핸드오프)에 걸리는 키워드인지도
확인하세요 — "답변 안 함" 규칙은 AI를 의도적으로 건너뛰고, "답변 후 인계" 규칙은
답을 하더라도 상담원을 호출합니다. 해당 문서의 카테고리에 **에이전트 범위**가 걸려
지금 에이전트가 그 지식을 못 보는 경우도 있습니다.

**Q. 상담원 답변이 전송되지 않습니다.**
모더레이션 차단입니다. 표현을 바꿔 재시도하고, 규칙이 과하면 master에게 조정을
요청하세요.

**Q. 대화가 저절로 종료됐습니다.**
방치 대화 자동 마무리입니다(30분 무응답 → 안내 → 종료, §4.4). 고객이 다시 메시지를
보내면 새 상담이 시작됩니다.

**Q. 이슈 보드가 안 보입니다.**
워크플로우 모드가 네이티브인 테넌트 전용입니다 — 플랫폼 관리자의 **요금제/애드온**
설정에서 `native`인지 확인하세요. 메뉴 자체가 없다면 제공 메뉴/직급 권한(2계층)을
확인하세요.

**Q. 설정 화면이 예전 설명과 다릅니다.**
`/settings`는 **8개 탭**(테넌트 설정)입니다(§14). 상담 전환(핸드오프)은 2026-10-24부터
별도 **상담원 연결** 탭에 있고, 메뉴 접근 권한은 *기타 설정* 탭에 있습니다.

**Q. 고객이 상담원을 불렀는데 상담카테고리 카드가 안 나옵니다.**
[상담원 연결 → 상담카테고리 관리]에서 **노출함**인 상담카테고리가 있는지 확인하세요.
노출함이 하나도 없으면 카드 없이 바로 연결합니다.

**Q. 규칙을 만들었는데 지정한 팀으로 배정되지 않습니다.**
규칙 위 **배정 확인**에 같은 조건을 넣어 보세요. 건너뛴 이유가 나옵니다. 흔한 원인은
업무 줄의 라벨 칩 사용, 권역 조건 누락, 팀원이 아직 초대를 수락하지 않음(배정 가능 0명)입니다.

**Q. 대시보드·통계 숫자가 예전보다 줄었습니다.**
정상일 수 있습니다 — 대화 수에서 AI 설정 **미리보기 세션이 제외**되었고, "해결"
정의가 통일되면서 고객이 마지막으로 말한 대화는 더 이상 해결로 세지 않습니다(§8·§9).

**Q. 위젯 설정을 바꿨는데 반영이 안 됩니다.**
위젯은 **고객의 다음 세션**부터 새 설정을 읽습니다. 위젯을 닫았다 열거나 새로고침하세요.

**Q. 고객이 알림(이메일 등)을 못 받습니다.**
① 콘솔의 알림 채널 정책에서 해당 채널이 켜져 있는지 ② 고객이 마케팅 수신 거부를
했는지(프로모션류만 영향) 순으로 확인하세요. 상점이 끈 채널은 고객이 켤 수 없습니다.

**Q. temperature를 바꿨는데 답변이 그대로입니다.**
Anthropic(Claude) 엔진에는 temperature가 적용되지 않습니다(모델이 거부하므로 전송하지
않음). max_tokens만 유효합니다.

**Q. AI 키가 없는데도 동작합니다.**
스텁(stub) 어댑터의 데모 응답입니다. 실서비스 전 반드시 실제 엔진을 등록·지정하세요.

**Q. 리뷰를 숨겼는데 고객에게는 보입니다.**
정상입니다 — 숨김은 스토어 노출만 제외하며 작성자 본인에게는 유지됩니다.
