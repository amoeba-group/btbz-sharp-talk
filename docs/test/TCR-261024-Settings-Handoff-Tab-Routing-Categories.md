실측 중 발견해 수정한 것:
- **변경이 없는데 [변경 저장]이 켜져 있었다.** 저장된 순서 번호(20, 30)와 화면이 다시 매긴 번호(10, 20)를 비교한 탓이다. 순서가 실제로 바뀌었을 때만 순서를 보내도록 고쳤다.
- **이름 없이 추가할 때 토스트에 코드가 그대로 나왔다**("central"). 기본 이름("중부")이 있으면 그 이름을 쓰도록 고쳤다.
