# 위젯 라운딩 토큰 전파 — 테스트 케이스·결과 (TCR-260917)

- 대상: T-001 ~ T-005 / 근거: PLN-260917 (FN-001~005, POL-001~002)
- 실행 환경: 로컬 빌드 산출물(`apps/widget/dist`) + Chromium 계산값 측정, 단위 테스트
- 스테이징/실몰 항목은 §3에 분리

## 1. 계산값 실측 — TC-001·002·003·005·007·008·009·010 (한 표로 통합)

실제 컴포넌트 클래스 문자열을 **빌드된 위젯 CSS**에 적용해 브라우저가 계산한
`border-radius`입니다.

| 컴포넌트(실제 클래스) | 기본(커스텀 없음) | 작게 | 보통 | 크게 |
|---|---|---|---|---|
| 첨부 칩·썸네일 (`rounded-st-xs`) | 4px | 3px | **4px** | 5px |
| `st-message` 말풍선 (`rounded-st-lg`) | 12px | 8px | **12px** | 16px |
| 버튼·목록 행 (`rounded-st-md`) | 8px | 5px | **8px** | 11px |
| 배지 (`rounded-st-sm`) | 6px | 4px | **6px** | 8px |
| 대형 카드 (`rounded-st-xl`) | 16px | 11px | **16px** | 21px |
| `st-launcher` (핀) | 9999px | 9999px | 9999px | 9999px |
| 모바일 패널 (`rounded-none`) | 0px | 0px | 0px | 0px |

| TC | 판정 | 근거 |
|----|------|------|
| TC-001 작게 | ✅ | 3/4/5/8/11 — POL-001 표 일치 |
| TC-002 보통 | ✅ | 4/6/8/12/16 — POL-001 표 일치 |
| TC-003 크게 | ✅ | 5/8/11/16/21 — POL-001 표 일치 |
| TC-004 무회귀(NFR-001) | ✅ | **보통 열 = 기본 열**. 폴백도 `var(--ivy-radius-lg, 12px)` 형태로 구 고정값과 동일 컴파일 확인 |
| TC-005 말풍선 추종 | ✅ | 8px → 16px |
| TC-006 빠른답장 | ✅ | 카드 변형은 `rounded-st-lg`로 이행, 칩 변형은 `rounded-full` 유지(소스 확인) |
| TC-007 버튼·목록 행 | ✅ | `--ivy-radius-md` 추종 |
| TC-008 핀/원형 제외 | ✅ | 전 설정 9999px |
| TC-009 모바일 사각 | ✅ | 전 설정 0px |
| TC-010 기본 테넌트 무영향 | ✅ | 변수 미설정 시 4/6/8/12/16 = 수정 전 값 |
