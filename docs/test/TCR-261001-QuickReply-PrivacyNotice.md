### 2-1. ① 버튼 404 — go2joy 테넌트(버튼 4개 전부 `message`)

```
POST /chat/scenario {action:"message", text:"체크인 방법 알려주세요"}
  동의 전 → 404 아님. 동의 게이트의 안내 문구(fail-closed, 정상)
  동의 후 → conversationId=673, senderType=ai
            "체크인 시간은 오후 2시 이후입니다… 조기 체크인은 추가 요금이…"
```

**404가 사라지고 KB 근거 답변이 나온다.** 보고된 증상의 해소를 실데이터로 확인.

### 2-2. ③ 고지 문구 — 테넌트별·언어별

| 테넌트 | 설정 | 결과 |
|---|---|---|
| go2joy(`commerce_enabled=0`, 프로필 미설정) | 없음 | `수집 항목: 채팅 메시지, 기본 기기 정보` — **"주문 조회 내역"이 사라짐** |
| amoebaorder(커머스, 미설정) | 없음 | `… 요청하신 주문 조회 내역 …` — **현행 유지**(배포로 바뀌지 않음) |
| amoebaorder, `locale=vi` | — | 베트남어 문구 |
| skyliving, `locale=en` | — | 영어 문구 |
