# TCR-261013 — Measurable guest / role gate: decideGate, traces, "Test as…", calibration (PLN-261012 SG-51, REQ D-13 / D-16), stream w3a

- Basis: PLN-261012 §3.2 **SG-51** + wireframe W3; REQ-261012 defects **D-13** (gate decisions leave no record) and **D-16** (the confidence is bimodal; with the stub embedder the gate never closes). Implementation report: `RPT-261013-w3a-gate-simulator`.
- Branch `feature/go2joy-s8-gate-simulator` (base `test/go2joy-integration` `689e9530`). Nothing pushed, nothing deployed.
- Vocabulary: **decision** = `allow | guest_gate | role_manager_only | low_confidence | embedder_degraded` (`GATE_DECISION`); **viewer** ("Test as…") = `guest | partner | receptionist | manager` (`GATE_AS`); **bar** = `GUEST_GATE_CONFIDENCE` (guest) / 0.45 handoff bar (everyone else); **leak** = a question that must be refused but was allowed; **over-refusal** = must be allowed, refused.
