## 3. 관찰 사항

- **"예약 진행" → `low_confidence` 핸드오프.** 검색어(FIX-260806 A2: 직전 고객 발화 2개+현재)가
  "…위에 알려줬어 / 1. 김익용 / 예약 진행"이 되어 KB 점수가 0.45에 못 미쳤다. 예약 확정이 사람에게 닿는다는 결과는 원하는 것이지만,
  원인이 설계가 아닌 검색 점수다. → PLN D2-A 규칙(`예약 진행` 등, `answer_then_handoff`)을 skyliving에 적용해 **의도된 경로**로 만들었다
  (대화 655 재실측: 대화 `waiting`, 상담원 호출). 답변을 먼저 보여 주려면 검색어에 직전 AI 발화를 넣는 튜닝이 필요하다(후속 후보).
- **회귀(ivyusa, EN, 대화 656)**: 후속 질문 "and for my teenage son?"이 앞 턴의 클렌저 맥락으로 답변됐다 ✅.
  첫 턴 "What is your return policy?"는 "정보가 없다"고 답했다. 이 턴은 이력이 없어 **변경 전과 동일한 호출**이다.
  분류기가 `product_inquiry`로 판정해 상품 그룹으로 검색이 기울어진 기존 현상이다(본 변경과 무관, 별도 점검 후보).
