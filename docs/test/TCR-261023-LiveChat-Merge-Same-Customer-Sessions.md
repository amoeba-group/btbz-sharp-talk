## 4. 엣지 / 미검증
- 메신저(카카오 등) 채널 대화는 `getOrCreateConversation`을 거치지 않고, 고객 신원도 없어 자동 추가 대상이 아니다(PLN 범위 밖).
- 대화 도중 로그인으로 신원이 생긴 세션은 **다음 고객 메시지**에서 가입한다. 로그인 순간에는 가입하지 않는다(설계).
- 핀 고정된 오래된 대화가 같은 방의 더 최근 대화에 접히면 핀 줄이 보이지 않는다. 대표 줄에는 핀 상태가 표시되지 않는다.
- 스테이징 실데이터(go2joy·ivyusa)로 통합·해제하는 확인은 배포 후 진행한다.
