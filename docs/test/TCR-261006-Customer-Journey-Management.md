## 3. 엣지
- 1세션 그룹: 멤버 제거 버튼 비활성(마지막 1명), 해제만 가능.
- 배너 숨기기는 대화별·화면 상태(새로고침 시 다시 보임).
- staff 등급은 `/users` 불가 → 담당자 목록은 `/journey/people`(이름만).
- 보드 메뉴는 메뉴 제공·권한 체계(`journey`, 상담 라벨) 대상 — growth 플랜 포함, starter 제외.
