# REQ-261023 — 위젯 헤더 버튼(언어 선택·설정) 노출 설정

## 요구사항 (원문)
> 채팅위젯에서 언어선택 버튼과 설정 버튼을 노출함/노출안함을 `https://shoptalk.amoeba.site/settings/widget` 설정에 추가함.
> 노출제한 (테스트모드) 사용함 / 사용안함 선택
> - 옵션 1 : 위젯노출설정 - IP
> - 옵션 2 : 언어, 설정버튼 노출설정 — 언어선택버튼 노출 안 할 경우 위젯은 화면의 언어선택을 따른다. (현재 되어있음)

## AS-IS

### 콘솔 `/settings/widget`
- `WidgetAccessCard` "노출 제한 (테스트 모드)" — 사용 중/사용 안 함 토글, 기간, 허용 IP, 허용 URL, 초대 키 (PLN-260929).
- 저장: `tenants.widget_access`(json) 하나, `PUT` 한 번. 판정식 = 제한 꺼짐 OR (기간 AND (IP OR URL OR 키)).
- 헤더 버튼 노출에 관한 설정은 **없음**.

### 위젯 헤더 (`apps/widget/src/components/widget/WidgetPanel.tsx:164-175`)
| 버튼 | 현재 노출 조건 |
|---|---|
| 언어 선택(🌐 `LanguageSwitcher`) | 트리거 모드가 아니고, 테넌트 제공 언어가 2개 이상일 때 |
| 설정(⚙ `PreferencesPanel`) | 항상 |
| 닫기(✕) | 플로팅 모드 또는 compact |

설정 패널 내용: 개인정보 동의 상태·철회/재동의, 마케팅 수신 거부, CCPA "판매·공유 거부", 내 데이터 내보내기/삭제(DSAR).
동의 안내 배너의 "개인정보 선택" 링크도 이 패널을 연다(`ConsentBanner.tsx:127`) — 단 배너는 동의 전에만 보임.

### "화면의 언어선택을 따른다" — 실제 동작 (`apps/widget/src/i18n/i18n.ts:107`, `public/embed.js:240,508-524`)
위젯 시작 언어 = ① 호스트가 **설정으로 지정한** 언어(`SHARPTALK_WIDGET_CONFIG.locale` → `host_locale=1`)
→ ② 방문자가 전에 고른 언어(localStorage) → ③ 브라우저 언어 → ④ EN. 각 단계는 테넌트 제공 언어만.
실행 중 변경은 호스트가 `SharpTalk.setLocale()`을 호출해야 반영.

| 호스트 페이지 방식 | 언어 버튼 숨김 시 결과 |
|---|---|
| 설정에 `locale` 지정 / 언어 바꾸면 페이지 새로고침 | ✅ 따름 (현재 되어있음 — 요구사항 말대로) |
| `setLocale()` 호출 | ✅ 따름 |
| `<html lang>`만 바꿈 (설정에 locale 없음) | ❌ 로더가 `?locale=`로 넘기긴 하나 `host_locale=1`이 없어 **추측값 취급** → 저장된 이전 선택·브라우저 언어가 이김 |
| SPA에서 새로고침 없이 `<html lang>` 변경 | ❌ 위젯이 모름 |

→ "현재 되어있음"은 **호스트가 설정으로 언어를 넘기는 스토어(go2joy HA 등)에 한해** 참. 언어 버튼을 숨기면 방문자가 위젯 안에서 고칠 방법이 사라지므로, `<html lang>`만 쓰는 스토어에서는 **이전 방문 때 고른 언어에 고정**되는 문제가 생긴다.

## TO-BE
1. `/settings/widget` 노출 카드에 **② 헤더 버튼 노출** 영역 추가: 언어 선택 버튼 [노출함/노출 안 함], 설정 버튼 [노출함/노출 안 함]. 기본값 = 노출함(현행 무회귀).
2. 위젯이 설정을 받아 헤더에서 해당 버튼을 렌더하지 않음.
3. 언어 버튼을 숨긴 테넌트에서는 위젯이 **화면(호스트 페이지)의 언어**를 따름 — `<html lang>`도 화면 선택으로 인정, 이전 방문의 수동 선택은 무시, SPA 언어 전환도 반영.
4. 설정 버튼을 숨겨도 개인정보 선택(동의 철회·CCPA 거부·DSAR) 경로는 남긴다.

## 사용자 흐름
1. 운영자(master/director) → 설정 › 위젯 → 노출 카드 ② 언어 선택 버튼 "노출 안 함" → 저장 → 토스트 "저장했습니다".
2. 쇼퍼가 스토어(한국어 페이지) 방문 → 위젯 헤더에 🌐 없음, 위젯은 한국어.
3. 쇼퍼가 스토어 언어 선택으로 영어 전환 → 위젯도 영어(새로고침형·SPA형 모두).

## 제약
- 노출 제한은 "노출 통제"이지 보안 경계가 아님(PLN-260929) — 버튼 숨김도 UI 선택일 뿐.
- 서버의 언어 허용 목록(widget_languages) 판정은 그대로 — 화면 언어가 제공 언어 밖이면 기존 규칙(EN 폴백).
- 스테이징 `DB_SYNCHRONIZE=false` — 스키마 변경이 생기면 SQL 선적용 필요(권장안은 스키마 변경 없음).
- i18n 6언어, 저장 성공/실패 토스트 필수.
