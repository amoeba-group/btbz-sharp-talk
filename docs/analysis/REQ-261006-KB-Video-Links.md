## 2. TO-BE
- AI 답변이 영상이 있는 지식을 근거로 쓰면, 답변 아래 출처 항목에 **[▶ 영상 보기]** 링크가 붙는다. 누르면 새 탭에서 바로 재생.
- 링크는 **코드가 붙인다**(인용된 문서에 영상 정보가 있을 때만). 모델이 URL을 지어내지 않는다.
- 링크는 오래 살아 있어야 한다(대화를 며칠 뒤 다시 열어도 동작) — 노션 서명 URL을 그대로 쓰면 1시간 뒤 깨진다.
- 기능은 범용(어느 테넌트든 문서에 영상 정보를 넣으면 동작), 데이터는 우선 go2joy만.

## 3. 갭
- G1 문서 ↔ 영상 연결 정보를 담을 곳이 없음
- G2 만료되는 노션 파일 URL을 오래 쓰는 링크로 바꿀 방법이 없음
- G3 출처 표시에 영상 링크 자리가 없음(상품 링크만)
- G4 신규 영상 12편에 대응하는 지식 문서가 없음(채팅·객실 등록 포함)

## 4. 제약
- go2joy 내부 교육 영상일 수 있음 → 링크를 아는 사람이 영상을 볼 수 있게 되는 것에 대한 go2joy 동의 필요(파트너 대상 가이드라 일반적으로 공개 의도로 보이나 확인)
- 노션 API 제한(초당 약 3회) — 클릭마다 호출하지 않도록 캐시
- 위젯 외 메신저 채널(카카오 등)은 출처 목록이 없음 — 이번 범위는 위젯·콘솔
