## 2. AS-IS (스테이징 실측 2026-10-01)

### 2.1 지식 (의견 3)
- 영상 가이드 51편은 8/29에 이미 KB 104건(VI/EN)으로 등재돼 있었다(PR #456).
- 그러나 9/16에 추가된 에이전트 **21 `hotel-admin`**은 카테고리 범위(`kb_categories.agent_ids`)에
  **"Hướng dẫn sử dụng Hotel Admin"(문서 1건) 하나**만 들어 있었다. 영상 카테고리 28개는
  `[9, 10]`(Admin Staff·Hotel Partner)에만 허용 → 테스터가 본 "참조 자료가 가이드·대시보드·
  용어집·Video 21·29 정도"와 정확히 일치(그 한 문서 안의 내용).
- 즉 **자료 부족이 아니라 에이전트 추가 시 범위를 같이 넓히지 않은 설정 누락**.
- 51편의 실제 구성: 대시보드 0, 리뷰 1, 객실유형(할인·플래시세일·추가요금·객실차단) 2~16,
  예약관리(취소·체크인·노쇼) 17~23, 리포트 24, 정산 25~31, 상품 32~33, 쿠폰 34~41,
  광고 42~45, **직원 관리 46~50**. **고객 채팅·로그인 영상은 없다.** 객실 "최초 등록"도
  공백(RPT-260829에서 이미 식별).

### 2.2 빠른 답변 버튼 (의견 1)
버튼은 두 종류다.
- **상단 시나리오 메뉴**: 테넌트 설정(`tenant_ai_config.scenario_buttons`, 콘솔 AI 설정).
  go2joy는 `cancel_refund` 버튼 1개(라벨 KO/VI만, agent 21 한정)였다.
- **답변 뒤 "다음 행동" 칩**: `apps/widget/src/components/chat/ChatTab.tsx` `fallbackActions`에
  **하드코딩** — My orders / Shipping & delivery / Return or exchange / Talk to an agent.
  RAG 답변처럼 자체 칩이 없는 답 뒤에 항상 나온다. **테스터가 본 버튼은 이것** — 설정으로 못 바꾼다.

### 2.3 인증 화면 (의견 2)
- go2joy `widget_tabs` = 3탭 → Notifications·Orders 탭이 커머스 로그인/비회원 주문조회 화면.
- 탭을 숨겨도 **채팅 안에서 같은 화면이 다시 나온다**: 분류기가 `needsOrderData`로 판정하면
  `chat.service.ts:777` 게이트가 "주문을 조회하려면 본인 확인이 필요합니다. 로그인하거나 비회원
  주문 조회를…" + 인증 카드. 실측: "오늘 예약 현황 보기"(KO) → 이 게이트에 걸림.
- 파트너 인증(호텔 ID·직원 권한)은 go2joy Hotel Admin의 로그인 정보가 필요 — SharpTalk 단독으로
  만들 수 없다. 이미 있는 **서명 신원 연동(embed_secret, PLN-260819)**에 호텔 ID·역할을 실어
  보내는 것이 자연스러운 경로이나 go2joy 측 서버 서명 구현이 선결.

## 3. TO-BE

| 항목 | TO-BE |
|------|-------|
| 지식 | 파트너 에이전트(10·21)가 같은 영상 카테고리를 본다 ✅ |

## 4. 제약
- ivyusa(프로덕션 LIVE)·다른 커머스 테넌트의 동작은 바뀌면 안 된다(기본값 = 커머스).
- 칩 라벨은 운영자가 이미 다국어로 관리하는 시나리오 버튼을 재사용(새 다국어 입력 화면 금지).
- AI가 실시간 예약 데이터를 보지 못한다 — "오늘 예약 현황"은 **보는 방법 안내**로 답한다.
