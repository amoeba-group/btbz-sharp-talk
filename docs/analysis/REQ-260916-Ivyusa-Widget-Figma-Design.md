## 5. 제약·전제
- 코드 변경은 모두 **테넌트 옵션**(기본값 = 현행 동작). ivyusa는 설정값으로만 Figma를 재현.
- 스토어 테마(Shopify) 헤더에 종 아이콘·배지를 넣는 것은 **테넌트 테마 작업**(스니펫 제공, 삽입은 IVY 측). 배지 수는 로더가 `unread-count`로 갱신.
- 알림 삭제는 소프트 삭제(감사 아님, 고객 본인 데이터) — 서버 `DELETE /notifications` 일괄 + 단건.
- Figma는 로그인 고객 기준. 게스트에게는 현행 신원 확인 카드 유지.
- 높이 760은 데스크톱만(모바일은 전체 화면 현행).
