## 2. 시안이 드러낸 사실 — 코드로 확인한 결과

시안 C의 "데이터 품질 플래그"와 A·C의 조치 항목을 코드와 대조했다. **하나는 오진, 셋은 원인 확정**(F3·F4는
2026-10-08 스테이징 실측)이다.

| # | 시안의 주장 | 코드 대조 결과 | 판정 |
|---|-------------|----------------|------|

추가로 코드에서 찾은 시안 외 사실:

- **F5** "Aware/Appeal은 관측 불가" 규칙은 상담 로그 기준으로만 맞다. `cjm_events`에는 상품 조회·찜·넛지
  (`Browse`)가 위젯에서 기록되므로 **Appeal 일부는 관측 가능**하다. 지금은 리포트가 이를 버린다.
- **F6** 메시지 구성의 "상담 3"은 `agentMessages = AGENT + AI`. 실측하면 **AI 2(칩 스크립트) + 사람 1**이다.
  "상담이 응답했다"의 주체를 알 수 없다(통계 쪽은 이미 AI/사람 분리 원칙).
- **F8** 시안의 "답변 잘림"(F2) 실측: AI 답변 278자, 사람 답변 341자 → 둘 다 200자에서 잘림.
- **F7** `avgLoops`는 대화가 0건이면 `null`이 아니라 `0`을 돌려준다 — 시안이 강조한 "0과 미측정 구분"을
  현재 METRICS가 일부 어기고 있다.
