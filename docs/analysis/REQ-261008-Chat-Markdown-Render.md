## 2. TO-BE
1. 위젯·콘솔 대화창에서 AI(와 상담원) 메시지의 **굵게·기울임·인라인 코드·글머리표·번호 목록·URL 링크**를 서식대로 표시한다(`**굵게**` → **굵게**).
2. 한 줄 미리보기(목록의 마지막 메시지)는 기호를 지운 평문으로 보여 준다.
3. 서식을 표시할 수 없는 메신저 채널로 보낼 때는 기호를 지운 평문으로 바꿔 보낸다(`**굵게**` → `굵게`, `- 항목` → `• 항목`).
4. **보안**: HTML을 해석하지 않는다. 메시지 안의 `<script>` 등은 글자 그대로 보인다(React 요소로만 렌더, `dangerouslySetInnerHTML` 미사용). 링크는 http/https만 연다.
