## 2. 단계

### P1 — 동일인 제안 (G1, G6)
- API `GET /agent/conversations/:id/related-sessions` — 같은 테넌트, 같은 `customer_id` 또는 같은 `email_hash`
  고객에 묶인 다른 세션 + 이미 속한 그룹. 미연결(게스트) 세션은 빈 목록.
- `POST /agent/groups` 재사용(묶기) / `POST /agent/groups/:id/members`(기존 그룹에 추가).
- `MIN_MEMBERS` 2→1 (D2). 멤버 제거 하한도 1. E5057 의미는 "0명 불가"로 유지.
- 콘솔: 대화 헤더 아래 배너 — 제안 0건이면 렌더 안 함.

```
┌ 대화 #714 ─────────────────────────────────────────────┐
│ 👥 같은 고객의 다른 세션 2건 (최근: 9/28 위젯, 9/12 카카오)  │
│              [타임라인으로 묶기]  [기존 그룹에 추가 ▾]  ✕   │
├────────────────────────────────────────────────────────┤
│  (대화 내용)                                            │
```

### P2 — 여정 카드: 단계·담당·할 일 (G2, G3, G7)
- 테이블
  - `journey_stages`(tenant_id, `key`, label JSON(언어별), sort_order, color) — 테넌트 첫 조회 시 5A 기본값 생성
  - `journeys`(tenant_id, group_id UNIQUE, stage_key, owner_user_id NULL, stage_changed_at, created_by)
  - `journey_tasks`(tenant_id, journey_id, title, due_at NULL, assignee_user_id NULL, done_at NULL, source `manual|report`, report_id NULL)
- 단계 변경 이력 = `audit_logs`(`journey.stage_changed`, from→to) — 그룹 이력과 같은 재사용 원칙.
- 여정은 그룹 방에서 처음 단계를 고를 때 생성(빈 그룹에 행을 미리 만들지 않음). 그룹 해제 시 여정·할 일 삭제(확인 문구에 명시).
- 리포트 화면의 "다음 행동" 항목 옆 [할 일로] → `source=report` 할 일 생성.
- 프로젝트 그룹 = 회사: 별도 회사 엔티티는 만들지 않고 그룹 이름을 회사명으로 사용(G7, 후속 백로그).
- 콘솔: 그룹 방 우측 패널(기존 고객여정분석 패널 상단)

```
┌ 고객여정 ─────────────────────────────┐

│ Ask 진입 3일 전 · 이력 ›                │

│ [고객여정분석 생성]  [비교]              │
└──────────────────────────────────────┘
```

### P3 — 여정 보드 (G4)
- 메뉴 `journey`(`/journey`, 라벨 consult) — 메뉴 제공·팀원 메뉴권한 체계에 등록.
- `GET /journey/board?kind=&owner=&overdue=` — 단계별 그룹 카드(이름·종류·담당·단계 체류일·미완료/기한 초과 할 일 수·마지막 대화).
- 카드를 다른 열로 끌면 단계 변경(P2와 같은 API, 감사 기록). 카드 클릭 → 라이브챗 그룹 방.
- 설정 > 여정 단계 카드: 단계 추가·이름(6개 언어)·순서·색. 사용 중인 단계 삭제는 거부(카드 이동 먼저).

## 3. 영향 분석

| 영역 | 영향 |
|------|------|
| 기존 그룹 | 최소 인원 완화 외 동작 동일. 기존 그룹은 여정 행 없음 → 카드가 "단계 미지정"으로 시작 |

## 4. 테스트 계획 (TCR에서 상세화)
- 제안: 동일 customer_id·email_hash 매칭 / 타 테넌트 미노출 / 게스트 빈 목록 / 이미 같은 그룹이면 제외.
- 단계: 변경 감사 1행, 존재하지 않는 단계 거부, 사용 중 단계 삭제 거부.
- 할 일: 생성·완료·기한 초과 집계, 그룹 해제 시 정리.
- 보드: 단계별 집계 = 개별 조회 합, 필터.
- 실부팅 + 스테이징 실화면(배너·보드 드래그·패널).
