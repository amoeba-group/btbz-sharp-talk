# PLN-261006 — 답변에 "영상 바로 보기" 링크

- 근거: [REQ-261006-KB-Video-Links](../analysis/REQ-261006-KB-Video-Links.md) G1~G4
- 상태: **승인 대기** — §1 결정 4건

## 1. 결정 필요 (권장 먼저)

| # | 질문 | 권장 | 대안 |
|---|------|------|------|
| D1 | 영상을 어떻게 보여줄까 | **A. 우리 서버 경유 링크** — 클릭 시 서버가 노션에서 새 재생 URL을 받아 바로 넘겨줌(302). 노션이 원본 그대로, 저장 0, 영상 교체도 자동 반영 | B. 영상 63편을 우리 저장소로 복사(빠르고 노션 무관, 단 노션에서 바꾸면 다시 복사) · C. go2joy가 노션 페이지를 '웹에 게시' → 노션 페이지의 해당 영상 위치로 링크(우리 개발 최소, 매뉴얼 전체가 공개됨) |
| D2 | 링크 공개 범위 | **영상 1편 단위 서명 링크**(문서별 HMAC, 추측·나열 불가). 링크를 받은 사람은 그 영상만 볼 수 있음 — go2joy 동의 필요 | 로그인한 위젯 세션에서만 재생(링크 공유 불가, 새 탭 재생 어려움) |
| D3 | 신규 영상 12편(채팅·객실 등록 포함) | **이번에 지식 문서로 추가**(8/29와 같은 프레임 분석 → VI/EN 문서, 영상 링크 포함) | 링크만 먼저, 문서화는 별건 |
| D4 | 범위 | **범용 기능 + go2joy 데이터** — 다른 테넌트도 문서에 영상만 지정하면 동작 | go2joy 전용 하드코딩 |

## 2. 단계

### P1 — 문서에 영상 지정 (G1)
- `kb_documents.video_ref varchar(255) NULL` — `https://…`(외부 재생 URL, 그대로 사용) 또는 `notion:<blockId>`(노션 업로드 영상, P2가 해석).
- 콘솔 지식 문서 편집에 "영상" 입력란 1개(선택). 일괄 등록 CSV에 `video_ref` 열(선택) — 기존 파일은 열이 없어도 그대로 동작.
- go2joy 데이터: 위 대응표로 `GTJ-VID-n-{VI,EN}` 102건에 `notion:<blockId>` 일괄 지정(스크립트, 재실행 안전).

### P2 — 오래 사는 재생 링크 (G2)
- 공개 라우트 `GET /api/v1/kb-videos/:docId?sig=…` — sig = HMAC(테넌트·문서 id). 검증 → `video_ref` 해석:
  - `https://` → 그대로 302
  - `notion:` → 테넌트 노션 토큰으로 블록 조회 → 새 서명 URL로 302. **Redis 50분 캐시**(서명 유효 1시간) — 클릭마다 노션 호출 안 함.
- 실패(토큰 만료·블록 삭제)는 안내 페이지(404 + 문구) + 서버 warn 로그. 문서 비활성/삭제 시 404.
- 서명 비밀은 기존 `CRED_ENC_KEY` 파생(새 env 없음).

### P3 — 답변에 링크 표시 (G3)
- 검색 결과를 출처로 만들 때 `videoUrl`(P2 서명 링크)을 함께 넣음 → 대화 기록(retrieval_trace)·답변 재사용에도 그대로 남음.
- 위젯 출처 목록:
```
(AI) 체크인은 예약 관리 → 체크인 대기 탭에서 …
 ─ 참고 자료 ─────────────────────
 · Video 21 — Processing a check-in
   [▶ 영상 보기]                ← 새 탭에서 재생
 · Hướng dẫn sử dụng Hotel Admin
```
- 영상 있는 출처는 목록 맨 위로. 콘솔 라이브챗(상담원 화면)의 AI 답변 출처에도 같은 링크.
- 6개 언어 문구, 상품 링크 표시는 무변경.

### P4 — 신규 영상 12편 지식화 (G4, D3 승인 시)
- 노션에서 12편 내려받아(일회성, 작업 PC) 8/29와 같은 방식으로 프레임 분석 → `reference/` 분석 문서에 추가 → 변환기로 VI/EN 24건 생성 → 일괄 등록(멱등 키 `GTJ-VID-51~62`), `video_ref` 포함, 카테고리 범위(agent 9·10·21) 적용.

## 3. 영향 분석
| 영역 | 영향 |
|------|------|
| 스키마 | 컬럼 1개(nullable) — 기존 문서 무변화. PR `## Migration` |
| 보안 | 공개 라우트 1개 — 서명 없거나 틀리면 404, 테넌트 경계 포함 서명, 노션 토큰·원본 URL은 응답에 미노출(302 대상만) |
| 성능 | 답변 경로 추가 쿼리 없음(문서 로드 시 같이 읽음), 재생은 캐시 |
| 무회귀 | 영상 없는 문서·다른 테넌트 출처 표시 동일, 상품 링크 동일 |

## 4. 테스트 계획
- 서명 검증(정상/변조/타 테넌트 문서), https·notion 해석, 캐시 적중, 노션 실패 시 404+로그
- 출처에 videoUrl 포함·재사용 답변에도 유지, 영상 없는 문서 무변화
- 일괄 지정 스크립트 재실행 멱등, 대응표 경계(16/17/50)
- 스테이징 실측: 체크인 질문 → [▶ 영상 보기] → 실제 재생
