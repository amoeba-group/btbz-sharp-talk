# PLN-261007 — FAQ 회귀 테스트 자동 채점 (R7)

- 근거: [REQ-261007-Go2Joy-FAQ-Accuracy](../analysis/REQ-261007-Go2Joy-FAQ-Accuracy.md) R7 — "44문항을 회귀 테스트 세트로 등록해 배포 전마다 자동 채점"
- **UI 변경 있음**(§3). **스키마 변경 있음**(§2 S1).
- 상태: **승인 대기**

## 1. AS-IS
- 골든 질문 회귀(FR-073, AI 설정 › 회귀 테스트): 질문 목록 → 실행 → 이전 실행과 **차이만** 보여 준다(신뢰도·길이·인용·문구 변경). **판정이 없다**(의도된 설계 — 문구 변화는 회귀의 증거가 아니라서).
- **최대 20문항**, 실행은 콘솔 지식 질의(`knowledge.ask`)를 쓰고 **에이전트를 지정하지 않는다**(페르소나·범위가 실제 위젯과 다름).
- 이번 go2joy 재측정은 별도 스크립트(위젯 API, 자동 사실 확인)로 했다. 화면에서 반복할 방법이 없다.

## 2. 단계
### S1 — 스키마 (`sql/261008-golden-graded.sql`)
- `golden_questions` + `expected` JSON(반드시 포함할 사실 — 문자열 배열, 대소문자·굵게 표시 무시) · `forbidden` JSON(포함되면 실패) · `ai_agent_id` BIGINT NULL
- `golden_runs` + `ai_agent_id` BIGINT NULL · `pass_count` INT · `fail_count` INT
- `golden_run_items` + `verdict` VARCHAR(8) NULL(`pass`/`fail`/NULL = 기대 사실 미지정) · `failed_checks` JSON

### S2 — 채점
- 순수 함수 `gradeAnswer(answer, expected, forbidden)`: 정규화(소문자, `**`·공백 정리) 후 포함 여부를 본다 → `{verdict, failedChecks}`
- **기본 금지어**(모든 질문에 적용): `▇▇▇`, `[PHONE]`, `[EMAIL]`, `[ADDR]`, `[CARD]`, `[ORDER]` — 이번에 고친 마스킹·치환 결함의 재발 감지
- 기대 사실이 없는 질문은 판정 없이 기존처럼 차이만 보고한다(기존 동작 보존)

### S3 — 실행 경로
- 실행 시 **에이전트를 선택**한다(`ai_agent_id`) → `knowledge.ask(…, aiAgentId)`로 페르소나·지식 범위를 위젯과 맞춘다
- 상한 20 → **60문항**(순차 실행 유지, 질문당 임베딩 1 + 생성 1)
- 비교 화면: 이전 실행 대비 **통과→실패(회귀)** 목록을 맨 위에 보여 준다

### S4 — 일괄 등록
- TSV 붙여넣기: `질문 ⇥ 기대 사실1|기대 사실2 ⇥ 금지어(선택)` 한 줄에 한 문항, 언어·에이전트는 일괄 지정
- 기존 질문과 문구가 같으면 기대 사실만 갱신한다(중복 생성 안 함)

### S5 — go2joy 세트 등록 (데이터)
- 44문항 + 기대 사실(FAQ 원문 기준). 예: D3 `Techcombank|19133261136016`, C1 `Chưa thanh toán|Chờ nhận phòng`, D4 `17|tháng sau`, B3 `Giảm sốc`, E2 `24`
- FAQ 미작성 문항(H2·I14)은 기대 사실 없이(판정 없음)

## 4. 영향
| 영역 | 영향 | 대응 |
|---|---|---|
| 기존 골든 세트 | 기대 사실 없음 → 판정 없음, 기존 차이 보고 그대로 | 하위 호환 |
| 비용 | 60문항 × (임베딩 + 생성) | 수동 실행만(자동 예약은 후속) |
| 스키마 | 열 추가 3테이블 | 스테이징·프로덕션 선적용 |

## 5. 결정 필요
- **D1. 실행 경로** — 권장: 콘솔 지식 질의 + 에이전트 지정(질문을 독립적으로 채점). 위젯처럼 한 대화로 이어 묻는 방식은 순서에 따라 결과가 흔들려 회귀 판정에 맞지 않는다.
- **D2. 배포 전 자동 실행** — 권장: 이번에는 수동 실행만. CI·배포 스크립트 연동은 후속(실 API 비용·시간 때문).
